本页对应王丽主编《概率论与数理统计》（科学出版社，2026 年第一版）第 66—69 页习题 3。请结合教材原题阅读；以下为重新推导的解答，不是出版社官方答案。连续型密度在边界上的单点取值不影响概率。

1｜有放回取球的联合分布

两次独立且每个编号等可能时，P(X=i,Y=j)=1/16，i,j∈{1,2,3,4}。因此 4×4 表格的 16 个格子都填 1/16，总和为 1。

2｜三角形区域上的均匀分布

由坐标轴及 y=2x+1 围成的区域为 −1/2≤x≤0、0≤y≤2x+1，面积为 1/4，故区域内联合密度 f=4，区域外为 0。

为清楚写分布函数，令 u=max(−1/2,min(x,0))，v=max(0,min(y,1))。若 u≤(v−1)/2，F(x,y)=(2u+1)²；若 u>(v−1)/2，F(x,y)=4uv+2v−v²。该式来自 F=4∫_(−1/2)^u min(v,2t+1)dt。将 x 或 y 截在区域边界，可统一处理区域外的值；边界两式相同。

3｜指数型联合密度

归一化给 k(1/3)(1/4)=1，所以 k=12。x>0、y>0 时 F(x,y)=(1−e^(−3x))(1−e^(−4y))；若 x≤0 或 y≤0，F=0。

P(0<X≤1,0<Y≤2)=(1−e⁻³)(1−e⁻⁸)。密度可分解为 3e^(−3x)·4e^(−4y)，所以两个边缘变量也独立。

4｜最大和最小点数

假设 n 次掷骰相互独立且骰子公平。对 k=1,…,6，P(max≤k)=(k/6)ⁿ，所以 P(max=k)=(k/6)ⁿ−((k−1)/6)ⁿ。

同理 P(min≥k)=((7−k)/6)ⁿ，故 P(min=k)=((7−k)/6)ⁿ−((6−k)/6)ⁿ。最大值和最小值各自的概率和均为 1。

5｜联合表求边缘分布

按行加得 P(X=0,2,5) 依次为 1/3、5/12、1/4；按列加得 P(Y=0,1,3) 依次为 1/2、1/3、1/6。分别检查各自概率和为 1。

6｜在区域上积分

0<x<1 时 f_X(x)=∫₀¹(2−x−y)dy=3/2−x，其余为 0。

要求 P(X−Y≤1/2)，可先求反面：区域为 1/2<x<1、0<y<x−1/2。对 2−x−y 在该三角形积分得到 1/8，因此答案为 7/8。

7｜先翻译离散事件

X、Y 都只能取 0 或 1，因此 XY≠1 与 X+Y≤1 是同一个事件；所求直接为 3/8。不需要额外假定 X、Y 独立。

8｜独立分布列相乘

按 X=−2、−1、0、1/2 为行，Y=−1/2、1、3 为列，联合概率矩阵为：

X Y=−1/2 Y=1 Y=3
−2 1/8 1/16 1/16
−1 1/6 1/12 1/12
0 1/24 1/48 1/48
1/2 1/6 1/12 1/12

每格由相应行概率乘列概率。题设明确独立，才能这样相乘。

9｜实根条件与面积

对方程中的未知数 x，判别式为 X²−4Y；有实根等价于 Y≤X²/4。联合分布在单位正方形上密度为 1，故概率为 ∫₀¹(X²/4)dX=1/12。

10｜利用独立求未知概率

第一行概率和为 1/3，第二行为 2/3。若独立，两行对应各列概率之比都为 1:2，故 α=2/9、β=1/9。代入可检查总和为 1 且每格等于边缘概率乘积。

11｜归一化与独立

∫₀¹∫₀¹cxy²dy dx=c/6=1，所以 c=6。边缘密度在 (0,1) 分别为 f_X(x)=2x、f_Y(y)=3y²；联合密度 6xy² 等于边缘密度之积，支持区域也一致，故独立。

12｜均匀和指数变量

X 的密度在 (0,1/5) 为 5，Y 的密度在 y>0 为 5e^(−5y)。由独立性，联合密度在 0<x<1/5、y>0 为 25e^(−5y)，其他处为 0。

P(Y≤X)=∫₀^(1/5)5(1−e^(−5x))dx=e⁻¹。

13｜二次方程有实根

按教材 E(0.5) 表示指数分布的率参数 λ=0.5，判别式为 4(X²−Y²)。在 X、Y 均非负的范围，有实根等价于 Y≤X。故概率 ∫₀¹(1−e^(−0.5x))dx=2e^(−1/2)−1≈0.2131。若另一本资料把参数记成均值，需要先换成对应的率。

14｜从条件密度构造联合密度

X 在 (0,1) 上密度为 1；给定 X=x，Y 在 (x,1) 均匀，故 f_(Y|X)(y|x)=1/(1−x)，x<y<1。联合密度为 1/(1−x)，范围 0<x<y<1。

f_Y(y)=∫₀ʸ1/(1−x)dx=−ln(1−y)，0<y<1；P(Y>1/2)=1−∫₀^(1/2)[−ln(1−y)]dy=(1+ln2)/2≈0.8466。

15｜给定 X 的条件密度

对 0<x<1，f_X(x)=∫ₓ¹6x dy=6x(1−x)。在 x=1/3 处 f_X=4/3，联合密度为 2，因此 f_(Y|X)(y|1/3)=3/2，范围 1/3<y<1；其他处为 0。检查积分为 (3/2)(2/3)=1。

16｜同值时合并概率

对 Z=X+Y，取值 −2、0、1、3、4 的概率依次为 1/4、1/10、9/20、3/20、1/20。其中 Z=1 来自两个格子，要相加。

对 W=X−Y，取值 −3、−2、0、1、3 的概率依次为 3/10、1/10、3/10、3/20、3/20。其中 W=0 来自两个格子，概率 1/4+1/20=3/10。两组概率都加至 1。

17｜均匀变量与指数变量相加

Z=X+Y，由独立性使用卷积。z≤0 时密度为 0；0<z<1 时 f_Z(z)=∫₀ᶻe^{−(z−x)}dx=1−e^(−z)；z≥1 时 f_Z(z)=∫₀¹e^{−(z−x)}dx=(e−1)e^(−z)。积分上下限由 0<x<1 且 z−x>0 同时决定。

18｜均匀变量的最大值和最小值

0<z<θ 时，F_M(z)=P(X≤z,Y≤z)=(z/θ)²，故 f_M(z)=2z/θ²。

P(N>z)=P(X>z,Y>z)=(1−z/θ)²，故 F_N(z)=1−(1−z/θ)²，f_N(z)=2(θ−z)/θ²。两密度在范围外均为 0，且各自积分为 1。

核对与范围
