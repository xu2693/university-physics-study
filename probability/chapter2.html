2.1 随机变量

教材习题：第二章课后题逐题讲解，包含解题条件和关键步骤。

2.1.1 随机变量的定义

试验的结果可以是文字，也可以是数字。为了计算，我们给每个样本点指定一个实数，这个对应规则叫随机变量，常用大写字母 X 表示；实际取得的数值常用小写 x 表示。随机的是试验结果，规则本身事先确定。

例如连续掷两次硬币，定义 X 为正面出现次数：X(正正)=2，X(正反)=X(反正)=1，X(反反)=0。不同的基本结果可以对应同一个数；事件 {X=1} 实际代表“正反或反正”。

2.1.2 分布函数

仅知道 X 的可能值还不够：还要知道它们有多可能。分布函数把不超过某个数 x 的概率累积起来：

F(x)=P(X≤x)，　−∞<x<+∞

x 向右移动，相当于把更多数值纳入统计，因此 F 不减；它介于0与1之间，左端极限为0，右端极限为1，并且右连续。右连续指从 x 的右侧趋近 x 时，函数值趋向 F(x)。这些条件共同刻画分布函数。

对 a<b，P(a<X≤b)=F(b)−F(a)。因为 F(b) 包含 X≤a 的部分，减去 F(a) 后，剩下 a<X≤b。若在 a 点存在概率，应特别留意端点：

P(X=a)=F(a)−F(a−)
P(a≤X≤b)=F(b)−F(a−)

F(a−) 表示从左侧趋近 a 的极限，即 P(X<a)。分布函数在该点的跳跃高度就是该点概率；不能不加判断地把小于和小于等于互换。

例1｜从分布列得到分布函数（新编）

某变量 X 取0、1、2的概率分别为0.2、0.5、0.3。求 F(x) 和 P(1≤X≤2)。

x<0 时没有取值被包含；0≤x<1 时只包含0；1≤x<2 时包含0和1；x≥2 时全部包含。

答案：F(x)依次为0、0.2、0.7、1；P(1≤X≤2)=0.5+0.3=0.8。

也可算 F(2)−F(1−)=1−0.2=0.8；若减 F(1)，会误删 X=1 的概率。

详细讲解与练习

为什么要把结果变成数字？

投两次硬币，样本结果可以写成“正正、正反、反正、反反”。如果我们关心的是正面出现几次，就给每个结果规定一个数：正正对应 2，正反和反正对应 1，反反对应 0。这个依试验结果而确定的数，叫随机变量，记为 X。

X 本身是随机变量；X=1 是一个事件，表示两次中恰好一次正面。写 X=1 不代表我们已经知道每次实验都会得到 1。

若硬币公平且两次独立，四个有序结果等可能，则：

x 0 1 2
P(X=x) 1/4 1/2 1/4

概率加起来等于 1。中间的 1/2 来自两种不同结果：正反与反正。

分布函数：一直累计到 x

分布函数定义为 F(x)=P(X≤x)。把它想象成从数轴左边出发，累计到 x（包括 x）为止的全部概率。

对前面两次掷硬币的 X：

  • x<0：F(x)=0；
  • 0≤x<1：F(x)=1/4；
  • 1≤x<2：F(x)=3/4；
  • x≥2：F(x)=1。

例如 F(1)=P(X≤1)=P(X=0)+P(X=1)=3/4，注意包含 X=1。F(1.5) 也是 3/4，因为 1 和 1.5 之间没有其他可能值。

分布函数不下降；x 向负无穷延伸时趋近 0，向正无穷延伸时趋近 1，并且右连续。直观地说，离散概率集中在某些点上，F 在这些点跳跃，跳跃高度就是该点的概率。

区间概率为什么是相减？

F(b) 包含 X≤b 的全部概率；减去 F(a)=P(X≤a)，剩下 a<X≤b：

P(a<X≤b)=F(b)−F(a)，其中 a<b。

左端点 a 被减掉，右端点 b 被保留。离散情形中端点可能带有非零概率，不能随意换成其他不等号。

例 2：对前面的 X，P(0<X≤2)=F(2)−F(0)=1−1/4=3/4。也可以直接相加 P(X=1)+P(X=2)=1/2+1/4=3/4。

2.2 离散型随机变量

2.2.1 分布列

可能取值有限或可列无限时，称为离散型随机变量。分布列列出各个可能值 xᵢ 和相应概率 pᵢ=P(X=xᵢ)，满足每个 pᵢ≥0，所有概率之和为1。其分布函数为 F(x)=Σxᵢ≤xpᵢ，是累加所得的阶梯函数。

例2｜求未知常数（新编）

X 取1、2、3的概率分别是 c、2c、3c，求 c 和 P(X≥2)。

所有可能值的概率和为1，因此 c+2c+3c=1，解得 c=1/6；再将 X=2 和 X=3 的概率相加。

答案：c=1/6，P(X≥2)=5/6。

检验：概率均非负、总和为1。

示意：例1中各取值的概率；柱子的高度表示概率，并非区间面积。

2.2.2 常用离散分布

0-1分布

一次试验只关注成功和失败，成功记1，失败记0。若成功概率为 p，0≤p≤1，则 P(X=1)=p，P(X=0)=1−p，称 X 服从参数 p 的0-1分布。

二项分布

同条件下独立重复 n 次，每次成功概率为 p，X 是成功次数，则 X∼B(n,p)，其中 n 为正整数、0≤p≤1：

P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，k=0,1,…,n

理由：指定哪 k 次成功时，独立性给出 pᵏ(1−p)ⁿ⁻ᵏ；选取成功位置有 C(n,k) 种，且这些情况互斥。试验次数固定、各次独立、成功概率不变，才能直接使用这个模型。

例3｜二项分布（新编）

一台设备每次独立启动成功率为0.8，尝试4次。求恰好成功3次的概率。

X∼B(4,0.8)。成功位置有 C(4,3)=4 种，每种概率为0.8³×0.2。

答案：4×0.8³×0.2=0.4096。

这里“恰好3次”与“至少3次”不同，后者还要加上4次成功的概率。

泊松分布

若某时间或区域内的事件次数 X∼P(λ)，λ>0，则 P(X=k)=exp(−λ)λᵏ/k!，k=0,1,2,…；λ 表示该区间的平均发生次数。事件数满足相应泊松过程条件时可用；有聚集或强烈相互影响时不能仅凭“计数”就断言泊松。

泊松近似：若 X∼B(n,p)，n 较大、p 较小，可令 λ=np，用泊松概率近似二项概率。更严格地，当 n→∞、pₙ→0、npₙ→λ>0 时，对固定 k，二项概率趋向 exp(−λ)λᵏ/k!。这是近似，使用前应说明条件。

例4｜泊松计数（新编）

设每小时故障数服从 λ=2 的泊松分布，求一小时内没有故障的概率。

代入 k=0，注意0!=1，2⁰=1。

答案：P(X=0)=e⁻²≈0.1353。

几何分布

独立重复试验，每次成功概率 p，0<p≤1，X 表示首次成功所需的试验次数，则 P(X=k)=(1−p)ᵏ⁻¹p，k=1,2,…。前 k−1 次都失败、第 k 次成功，所以相乘。P(X>k)=(1−p)ᵏ。某些资料把 X 定义成首次成功前的失败次数，起点为0，使用时要看清定义。

无记忆性：对非负整数 m、n，在条件事件概率大于0时，P(X>m+n | X>m)=P(X>n)。已经连续失败多少次，不改变未来独立试验的成功率；这并非说现实中每一种重复过程都独立。

超几何分布

从 N 件物品中等可能地不放回抽 n 件，其中 M 件是目标品，X 是抽到的目标品数：

P(X=k)=C(M,k)C(N−M,n−k)/C(N,n)

可取范围为 max(0,n−(N−M))≤k≤min(n,M)。分子先选目标品再选其他品，分母是全部等可能组合。不放回通常不是二项分布。

例5｜首次成功与不放回（新编）

独立试验每次成功率0.25，求第3次才首次成功的概率；另从5个物品（2个次品）中无放回取2个，求恰有1个次品的概率。

前者要求失败、失败、成功；后者采用无序组合。

答案：0.75²×0.25=0.140625；C(2,1)C(3,1)/C(5,2)=0.6。

详细讲解与练习

分布列：离散情形的完整说明

当 X 只能取有限个或可数个值时，可以列出每个值及其概率，这个对应关系叫分布列。每个概率不得为负，所有可能取值的概率总和为 1。

例 1：已知 P(X=0)=a，P(X=1)=2a，P(X=2)=3a，且只有这三个可能值。求 a 与 P(X≥1)。

第一步，利用总概率为 1：a+2a+3a=1，因此 a=1/6。第二步，X≥1 包含 1 和 2，两个事件互斥，所以 P(X≥1)=2/6+3/6=5/6。最后检查：三个概率非负且和为 1。

二项分布：先检查四个条件

若进行 n 次试验，每次只有成功或失败；各次独立；每次成功概率都为 p；X 记录成功次数，则 X 服从二项分布：

P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，k=0,1,…,n。

先理解每部分：选出 k 次成功的位置有 C(n,k) 种；每种特定排列的概率为 pᵏ(1−p)ⁿ⁻ᵏ；互不重叠的排列概率相加，得到公式。

例 4：一次成功概率为 0.2，独立尝试 3 次。恰好成功 1 次的概率为 C(3,1)×0.2×0.8²=3×0.2×0.64=0.384。至少成功 1 次可用对立事件：1−0.8³=0.488。“恰好一次”和“至少一次”不能混用。

不放回抽样通常使各次成功概率发生变化，不能不加判断地直接套二项分布。

先分清三件事

第一，X 记录的是什么：成功次数、等待时间、测量值，还是别的量？第二，X 能取哪些值：离散的整数还是连续区间？第三，题目给出的独立性、成功概率、时间单位等，是否支持使用某个分布？不要因为题里有“概率”就套二项分布，也不要因为数据看起来像钟形就断言严格正态。

概率质量函数 P(X=k) 适用于离散取值；连续型随机变量的密度 f(x) 用区间积分求概率。两者都要求总概率为 1。

两点分布与二项分布

一次伯努利试验只有成功和失败，成功概率为 p。令成功时 X=1、失败时 X=0，则 P(X=1)=p，P(X=0)=1−p，E(X)=p，D(X)=p(1−p)。这只是编码方式，“成功”未必是好事，也可以代表发生故障。

n 次独立试验中成功概率都为 p，成功次数 X∼B(n,p)：P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ，k=0,…,n；E(X)=np，D(X)=np(1−p)。独立和每次成功率不变是模型条件。

例 1：独立试验 4 次，每次成功率 0.5，恰好成功 2 次概率为 C(4,2)(0.5)²(0.5)²=6/16=3/8。至少成功一次的概率为 1−(0.5)⁴=15/16；二者问法不同。

泊松分布：某区间内的事件数

若 X 服从参数 λ>0 的泊松分布，P(X=k)=e^(−λ)λᵏ/k!，k=0,1,2,…，E(X)=D(X)=λ。在泊松过程模型中，λ 可表示所选时间或空间区间的平均事件数。

先检查 λ 对应的区间长度：如果平均每小时 3 次，模型假设发生率稳定，那么 2 小时区间的参数为 6，不是仍取 3。现实事件是否满足独立增量、恒定发生率等条件，需要结合背景判断，不能一见到“次数”就默认泊松。

例 2：每小时事件数服从参数 2 的泊松分布。一小时内无事件概率为 e⁻²≈0.1353；至少一次概率为 1−e⁻²≈0.8647。答案来自对立事件。

二项分布与泊松近似

教材第 26 页给出泊松定理：若 Xₙ∼B(n,pₙ)，当 n 趋于无穷且 npₙ→λ>0，对每个固定的 k，二项概率趋于 e^(−λ)λᵏ/k!。实际计算时，当 n 较大、p 较小且 λ=np 与问题规模相适应，可考虑用参数 λ=np 的泊松分布近似二项分布；具体精度需视 n、p 和关心的概率而定，不能把经验阈值当成精确保证。

例： 某项独立事件每次发生概率 0.01，共进行 100 次。X∼B(100,0.01)，λ=np=1。无事件的精确概率为 0.99¹⁰⁰≈0.3660；泊松近似为 e⁻¹≈0.3679。近似和精确值接近，但并不完全相等。

几何分布：第一次成功要等几次？

若每次试验独立、成功概率恒为 p，且 0<p≤1，令 X 为第一次成功时的试验次数，则 X 可以取 1、2、3，…，分布为 P(X=k)=(1−p)^(k−1)p。前 k−1 次必须失败，第 k 次成功，因此有 k−1 个失败因子。这个定义与“第一次成功前失败了几次”的另一种记法不同，后者从 0 开始；读题时必须先确认。

P(X>k)=(1−p)^k：第一次成功次数大于 k，表示前 k 次全部失败。对非负整数 s、t，在条件事件概率非零时，P(X>s+t|X>s)=P(X>t)，这称为无记忆性：已失败的次数不改变之后独立试验的成功概率。

例： 每次独立成功概率 0.2，问第三次才首次成功的概率。前两次失败、第三次成功，概率为 0.8²×0.2=0.128。已知前两次都失败，第三次成功概率仍为 0.2；它与“从开始算第三次才成功”的 0.128 不是同一个条件问题。

教材第 27 页将 X 定义为首次成功的试验次数，因此本篇使用 1、2、3 起算的约定。连续等待时间中指数分布也有无记忆性，但一个是离散试验次数，一个是连续时间，不能把公式的变量和单位混为一谈。

练习与解答

1. 3 次独立尝试，每次成功概率 0.2，求恰好 1 次成功的概率。

解：C(3,1)×0.2×0.8²=0.384。题目若问至少一次，答案是 1−0.8³=0.488。

2. X∼Pois(3)，求 P(X=0)。

解：e⁻³3⁰/0!=e⁻³≈0.0498。

3. X 在 2 到 6 上均匀分布，求 P(X>5)。

解：区间长度之比为 (6−5)/(6−2)=1/4。

4. X∼N(10,4)，求 P(X≤12)。

解：方差为 4，所以标准差为 2；z=(12−10)/2=1，答案 Φ(1)≈0.8413。

2.3 连续型随机变量

2.3.1 密度与概率

对连续型变量，若存在非负函数 f，使 F(x)=∫−∞xf(t)dt，则 f 是概率密度。直观上，密度曲线下、横轴上某一区间的面积是该区间的概率；总面积为1。密度值本身不是某一点的概率，也不必小于1。若 X 以小时计量，密度的单位是每小时，积分后概率没有单位。

P(a<X≤b)=∫abf(x)dx=F(b)−F(a)

积分可理解为把许多窄条面积相加；求导则是反向考察累计量的变化率。在 f 连续处，F′(x)=f(x)。连续型变量 P(X=a)=0，因此单个端点取不取不影响区间概率；这不适用于有跳跃的分布。

例6｜由密度求概率（新编）

已知 f(x)=2x（0≤x≤1），其他地方为0。求 P(X≤1/2)。

先核验：f 非负，∫₀¹2x dx=[x²]₀¹=1。再累积0到1/2的面积：∫₀¹ᐟ²2x dx=[x²]₀¹ᐟ²。

答案：P(X≤1/2)=1/4。

这里 f(1/2)=1 是密度高度，不是 P(X=1/2)；后者为0。

蓝色阴影表示 a 到 b 间的概率；密度曲线为示意图，面积而非高度表示概率。

2.3.2 常用连续分布

均匀分布

X∼U(a,b)，a<b，密度在 (a,b) 内为 1/(b−a)，其他位置为0。任一子区间的概率等于该区间长度除以 b−a；密度是常数，表示等长区间概率相同。

指数分布

X∼E(λ)，λ>0，密度为 λe⁻λˣ（x>0），其余为0。F(x)=1−e⁻λˣ（x>0），x≤0时为0；因此 P(X>t)=e⁻λᵗ（t≥0）。λ 的单位是时间单位的倒数。指数分布具有无记忆性：P(X>s+t|X>s)=e⁻λ⁽ˢ⁺ᵗ⁾/e⁻λˢ=e⁻λᵗ，s,t≥0。

例7｜指数等待时间（新编）

等待时间 X 以小时计，服从参数 λ=0.5/小时的指数分布。求等待超过2小时的概率，以及已等1小时后再等超过2小时的条件概率。

前者用尾概率 e⁻⁰·⁵×²；后者由无记忆性等于相同的尾概率。

答案：两者均为 e⁻¹≈0.3679。

这个结论依赖指数模型，不能套用到任意寿命分布。

正态分布

X∼N(μ,σ²)，σ>0，密度 f(x)= [1/(σ√(2π))] exp[−(x−μ)²/(2σ²)]。曲线以 μ 为中心对称，σ 越大越分散；记号中的第二个参数是方差 σ²，不是标准差 σ。

标准化 Z=(X−μ)/σ，则 Z∼N(0,1)。记标准正态分布函数为 Φ，Φ(−z)=1−Φ(z)，于是 P(a<X≤b)=Φ((b−μ)/σ)−Φ((a−μ)/σ)。Φ 通常查表或用计算器。约有68.27%、95.45%、99.73%的概率分别落在 μ±σ、μ±2σ、μ±3σ 范围内；这是正态模型下的近似值。

例8｜正态标准化（新编）

某指标 X∼N(100, 15²)，求 P(85<X≤115)。

两端分别标准化为 −1 与 1；由对称性，Φ(1)−Φ(−1)=2Φ(1)−1。取 Φ(1)≈0.8413。

答案：约0.6826。

检查：范围以均值为中心、半宽一个标准差，应接近68%。

详细讲解与练习

连续随机变量：概率是面积，不是曲线高度

若存在非负函数 f，使得区间概率可由 f 在区间下的面积计算，f 称为概率密度函数。总面积为 1。对于连续随机变量，P(X=a)=0，因此区间端点是否包含，对概率没有影响。

密度 f(a) 是曲线在 a 处的高度，不是 P(X=a)。密度的数值甚至可以大于 1：比如 X 在 0 到 0.5 均匀分布，密度是 2，但整个矩形面积仍为 0.5×2=1。概率不能大于 1，密度高度不受同一限制。

例 3：从密度求概率

设 X 在 0 到 2 上均匀分布，其密度在该区间为 1/2，在其他位置为 0。求 P(0.5<X≤1.5)。

关注区间长度是 1，密度高度是 1/2，所以面积为 1×1/2=1/2。P(X=1)=0；f(1)=1/2 是密度高度，两者不是一回事。

分布函数可写为：x<0 时 F(x)=0；0≤x≤2 时 F(x)=x/2；x>2 时 F(x)=1。于是 F(1.5)−F(0.5)=0.75−0.25=0.5，与面积法一致。

练习与详细解答

1. X 取 0、1、2，概率分别为 0.2、0.3、0.5。求 F(1)、P(0<X≤2)。

解：F(1)=0.2+0.3=0.5。P(0<X≤2)=0.3+0.5=0.8，也等于 F(2)−F(0)=1−0.2。

2. X 在 0 到 4 均匀分布，求 P(1≤X≤3)、P(X=2)。

解：密度为 1/4，区间长度为 2，概率为 2×1/4=1/2。连续随机变量在单点的概率 P(X=2)=0。

3. 某次独立尝试成功概率为 0.5，重复 4 次，求恰好成功两次的概率。

解：选成功位置有 C(4,2)=6 种，每种概率为 0.5⁴=1/16，所以答案为 6/16=3/8。题中独立且成功率固定，才可使用二项公式。

均匀分布：区间内密度恒定

X 在 [a,b] 上均匀分布，a<b，其密度在该区间为 1/(b−a)，在其他位置为 0。若 [c,d] 包含在 [a,b] 内，P(c≤X≤d)=(d−c)/(b−a)。期望为 (a+b)/2，方差为 (b−a)²/12。

例 3：等待时间 X 在 0 到 10 分钟上均匀分布，等超过 7 分钟的概率是 (10−7)/10=0.3，平均等待为 5 分钟。这里假定整个区间均匀，并不是任何等待问题都适合均匀分布。

指数分布：等待时间模型

参数 λ>0 的指数分布密度为 f(x)=λe^(−λx)（x≥0），x<0 时为 0。其分布函数为 F(x)=1−e^(−λx)（x≥0），所以 P(X>t)=e^(−λt)，t≥0；E(X)=1/λ，D(X)=1/λ²。

这里 λ 的单位是时间的倒数。例如时间以小时计时，λ 单位为每小时；若把时间改为分钟，参数数值也要相应换算。指数分布具有无记忆性：对 s,t≥0，P(X>s+t|X>s)=P(X>t)。这是模型的性质，不是所有等待时间都无记忆。

例 4：X 服从每小时参数 λ=0.5 的指数分布，等待超过 2 小时的概率为 e⁻¹≈0.3679，平均等待为 2 小时。平均等待 2 小时不意味着每次都恰好等 2 小时。

正态分布：标准化以后查表

若 X∼N(μ,σ²)，μ 为均值，σ² 为方差，σ>0 为标准差。密度关于 μ 对称，但“正态”不只是对称，还包含特定的密度形状。

令 Z=(X−μ)/σ，则 Z∼N(0,1)。记标准正态分布函数 Φ(z)=P(Z≤z)，则 P(X≤x)=Φ((x−μ)/σ)。注意第二个参数写成 σ² 的教材约定；标准化分母是 σ，不是 σ²。

例 5：X∼N(100,10²)，求 P(X≤120)。标准化 z=(120−100)/10=2，所以概率 Φ(2)≈0.9772。由对称性，P(X≥120)=1−Φ(2)≈0.0228。

2.4 一维随机变量函数的分布

已知 X 的分布，研究 Y=g(X) 的分布。先确定 Y 的可能取值，再把关于 Y 的事件翻译成关于 X 的事件；不要只把密度里的 x 机械替换成 y。

离散型：合并相同结果

例9｜平方后合并概率（新编）

X 取 −1、0、1 的概率分别为0.2、0.3、0.5，令 Y=X²，求 Y 的分布列。

−1 与1都变成1，对应事件互斥，所以概率相加；0仍变成0。

答案：P(Y=0)=0.3，P(Y=1)=0.7。

连续型：先求分布函数

通用方法是 Fᵧ(y)=P(Y≤y)=P(g(X)≤y)：解不等式，求 X 在对应区域的概率，再在可导处求导得到密度。若 g 在相关范围严格单调、可微且逆函数 h 可微，则可用 fᵧ(y)=fₓ(h(y))|h′(y)|，并另写 y 的取值范围。绝对值确保密度非负；不单调时可能有多个逆分支，需要分别计入。

推导要点：g 递增时，Y≤y 等价于 X≤h(y)，故 Fᵧ(y)=Fₓ(h(y))；对 y 求导得到 fₓ(h(y))h′(y)。g 递减时不等号方向翻转，导数多出负号；两种情况统一成绝对值。

平方为何有两支？

例如 Y=0.25 既可能由 X=0.5 产生，也可能由 X=−0.5 产生。如果只保留正根，会漏掉另一部分概率。

例10｜平方变换（新编）

X∼U(−1,1)，令 Y=X²。求 Y 的分布函数和密度。

Y 只能在0到1之间。当 0≤y≤1，Y≤y 等价于 −√y≤X≤√y。均匀分布的区间概率为长度之比，所以 Fᵧ(y)=2√y/2=√y。y<0 时 Fᵧ=0，y≥1 时 Fᵧ=1。对中间区间求导。

答案：fᵧ(y)=1/(2√y)（0<y<1），其他地方为0。

检验：∫₀¹1/(2√y)dy=1。虽然密度在0附近很高，其面积仍有限；X 的正、负两支都已包括。

若 X∼N(μ,σ²)，且 Y=kX+b、k≠0，则 Y∼N(kμ+b,k²σ²)。k 为负时图形会反向，但方差仍为正。

详细讲解与练习

先确定新变量可能取什么值

已知随机变量 X，定义 Y=g(X)。Y 的分布不是简单把 X 的公式中的 x 替换为 y；一般要先求 F_Y(y)=P(Y≤y)，将不等式转换为关于 X 的事件，然后按 X 的已知分布计算。

例 1：平方变换。 X 在 [−1,1] 均匀分布，Y=X²。Y 的范围为 [0,1]。当 0≤y≤1，Y≤y 等价于 −√y≤X≤√y，区间长度为 2√y，总长度为 2，所以 F_Y(y)=√y。y<0 时 F_Y(y)=0，y≥1 时 F_Y(y)=1。对 0<y<1 求导，得到密度 f_Y(y)=1/(2√y)。

为什么不是只看 X≤√y？因为平方不是一一对应：正负两个方向都可能产生同一个 Y。端点处密度表达式发散不妨碍其在区间上的积分为 1；连续随机变量单点概率仍为 0。

单调变换与雅可比

如果 Y=g(X) 在相关区间严格单调、可微，且逆函数满足适当条件，可用 f_Y(y)=f_X(g⁻¹(y)) |d g⁻¹(y)/dy|，并写清 Y 的支持范围。绝对值保证递减变换时密度不因导数为负而变负；多对一变换则须把各个满足条件的逆分支贡献相加。

例 2：线性变换。 X 在 [0,1] 均匀分布，Y=2X+1。Y 的范围为 [1,3]；逆函数 x=(y−1)/2，导数为 1/2，所以 Y 在 [1,3] 的密度为 1/2，其他位置为 0。总面积 2×1/2=1，可用于检查。

自学检验：分布函数和概率密度有什么不同？

先自己想一想：设 X 在 0 到 2 上均匀分布。求 P(0.5<X≤1.5)，并说明 P(X=1)。

查看详细解答

密度在 0 到 2 内为 1/2，区间长度为 1，所以所求概率为 1×1/2=1/2。单点长度为 0，因此 P(X=1)=0。密度在 x=1 处的值是 1/2，它不是 P(X=1)；概率要看密度曲线下的面积。
