第6章　统计量及其分布

概率论常从已知模型推算数据；统计推断则利用样本反推总体。本章建立两者之间的桥梁。

本章目录6.1 基本概念6.2 抽样分布回顾

依据：王丽主编《概率论与数理统计》，科学出版社，2026年第一版，第6章，纸页 98—114。教材例题标有原编号，其余练习为自学补充。

6.1 基本概念

教材习题：第六章课后题逐题讲解，包含解题条件和关键步骤。

6.1.1 总体与样本

总体是研究对象的全部，个体是其中一个对象。关注某一数值指标时，可用随机变量 X 的分布描述总体指标；例如一批灯泡的寿命。总体参数是描述总体的固定但可能未知的数，例如平均寿命 μ。

样本 X₁,…,Xₙ 是抽样之前的随机变量；实际测得的数据 x₁,…,xₙ 是样本值，n 是样本量。教材中的简单随机样本通常指 Xᵢ 相互独立并与总体同分布。真实抽样若有聚集、偏选或不放回且抽样比例很大，不能不加说明地假定独立同分布。

独立让联合分布分解成各项乘积，同分布让每项使用同一个总体分布。譬如两次观测都不超过给定界限的概率是 F(x₁)F(x₂)。离散时乘单次的概率质量，连续时乘单次的密度。

教材例 6.1｜由总体得到样本联合分布

伯努利样本的一个有序结果 (x₁,…,xₙ) 中有 k 个 1，它的概率为 pk(1−p)n−k。如果只问 1 的总数为 k，要把 C(n,k) 个这样的排列加起来，才得到二项分布的概率。

若总体是速率 λ 的指数分布，每个 xᵢ 都大于零时，乘积密度为 λn exp(−λΣxᵢ)。任意一个坐标不在支持区间内时，联合密度取零。

6.1.2 经验分布函数

给定样本值后，经验分布函数 Fₙ(x) 是样本中不超过 x 的比例：Fₙ(x)=#{i：xᵢ≤x}/n。每遇到一个样本值就上升；重复值使同一点的跳跃更大。它由样本得到，用来估计总体分布函数，换一次样本可能不同。

例1｜经验分布函数（新编）

样本为2、1、2、4，求 F₄(2) 和 F₄(3)。

四个数据中不超过2的有1、2、2共三个；不超过3的仍是这三个。

答案：F₄(2)=3/4，F₄(3)=3/4。

等于2的两个样本都应计入，因为定义使用 ≤。

教材例 6.2｜重复值要一次跳多格

八个数据排序后为 2、2.5、2.5、2.5、2.7、3、3、3.5。从最小值左边开始，逐段累计为 0、1/8、4/8、5/8、7/8、1。每段从对应的跳点本身开始。例如 F₈(2.5)=4/8，而 F₈(2.5−)=1/8，差值 3/8 正好是三次 2.5 的比例。

固定 x 时，计数可写作 n 个指标 I(Xᵢ≤x) 之和，每个指标的期望为 F(x)。由大数定律，固定 x 的经验比例会靠近 F(x)。格利文科定理更强，在独立同分布的抽样下，所有 x 上的最大绝对偏差 supx|Fₙ(x)−F(x)| 随 n 增大几乎必然趋近零。某次新增观测仍可能暂时使偏差变大。

自测重复值的计数

观测 2、3、3、6、8 中，不大于 3 的有三个，故 F₅(3)=3/5。两个 3 各计一次。

6.1.3 统计量

统计量是只由样本和已知常数构成、不含未知参数的函数。抽样前它是随机变量，抽样后得到一个具体数值。常见统计量：

样本均值 X̄=ΣXᵢ/n
样本方差 S²=Σ(Xᵢ−X̄)²/(n−1)，n≥2

样本标准差 S=√S²；样本 k 阶原点矩为 ΣXᵢᵏ/n，k 阶中心矩为 Σ(Xᵢ−X̄)ᵏ/n。注意二阶中心矩分母为 n，而本书样本方差分母为 n−1。

例如 μ 已知而 σ 未知时，X₁+μ 可以直接用数据算出，而 (X₁−μ)/σ 还需要未知 σ。后者可以有已知的概率分布，第7章就会用它一类的式子反解参数。

教材例 6.3｜为什么样本方差除以 n−1

用 ΣXᵢ=nX̄ 化简平方和，得 Σ(Xᵢ−X̄)²=ΣXᵢ²−nX̄²。独立同分布且方差有限时，E(X̄)=μ，且独立使方差可相加，所以 D(X̄)=σ²/n。

分别代入 E(Xᵢ²)=σ²+μ² 与 E(X̄²)=σ²/n+μ²，得到离差平方和的期望 n(σ²+μ²)−n(σ²/n+μ²)=(n−1)σ²。要让 E(S²)=σ²，就除以 n−1。离差和为零也说明最后一个离差由其他 n−1 个确定。

自测样本均值的波动

独立同分布样本容量 64，总体均值 20、标准差 8。求样本均值的期望和标准差。

由上式得到 20 和 √(8²/64)=1。计算这两个数字只需有限方差和独立同分布。

例2｜均值和样本方差（新编）

样本数据为1、2、3，求样本均值和样本方差。

均值为2；三个离差是−1、0、1，平方和为2。样本量3，所以样本方差除以2。

答案：x̄=2，s²=1，s=1。

如果除以3得到2/3，那是这里所说的二阶样本中心矩，而不是本书定义的样本方差。

样本排序后得到次序统计量 X₍₁₎≤…≤X₍ₙ₎；最小、最大值之差称样本极差。样本中位数在奇数个时取中间数，偶数个时取中间两个数的平均。对独立同分布样本，最大值不超过 x 等价于每个都不超过 x，故其分布函数为 F(x)n。最小值大于 x 的概率是 [1−F(x)]n，取补集得到最小值的分布函数。若总体有密度 f，分别求导即得最大值密度 nF(x)n−1f(x)，最小值密度 n[1−F(x)]n−1f(x)。

教材例 6.4　观测 (3,1,0) 排成 (0,1,3)，所以样本中位数为 1，极差为 3。原第一个观测值可以成为排序后的最大值。

6.2 抽样分布

同样的总体、同样的抽样方式反复取样，每次得到的统计量通常不同；这些统计量的概率分布称抽样分布。它不是某一次数据的直方图，而是“重复抽样下统计量会怎样变化”的模型。

6.2.1 χ² 分布

若 Z₁,…,Zᵥ 相互独立且均服从 N(0,1)，则 Q=ΣZᵢ² 服从自由度 v 的卡方分布，记 χ²(v)。它只取非负值，形状由自由度决定；E(Q)=v，D(Q)=2v。独立卡方变量相加，自由度相加。

教材例 6.5　用真实均值 μ 居中、用 σ 标准化时，n 个 (Xᵢ−μ)/σ 独立标准正态，平方和服从 χ²(n)。改用样本均值居中后自由度减一，原因见后面的抽样定理。

标准正态 Z 的二阶矩为 1。由密度 φ 的导数 φ′(z)=−zφ(z)，对四阶矩分部积分可得 E(Z⁴)=3E(Z²)=3。所以 D(Z²)=3−1²=2，独立相加便得到卡方的均值和方差。卡方密度在 x>0 时为 xv/2−1e−x/2/[2v/2Γ(v/2)]。

6.2.2 t 分布

若 Z∼N(0,1)、Q∼χ²(v) 且相互独立，则 T=Z/√(Q/v) 服从 t(v)。t 分布关于0对称，自由度较小时尾部比标准正态更厚；自由度增大时趋近标准正态。估计正态总体均值、总体标准差未知时会用到它。

自由度大时，Q/v 是 v 个独立标准正态平方的平均，按大数定律靠近 1，所以这个随机分母的影响逐渐减弱。小自由度时，用 t 分位数才能保留尾部差异。例如上侧 0.025 分位数 t0.025(4)≈2.776，大于正态的 1.960。

6.2.3 F 分布

若 Q₁∼χ²(v₁)、Q₂∼χ²(v₂) 且独立，则 F=(Q₁/v₁)/(Q₂/v₂) 服从 F(v₁,v₂)。它非负，两个自由度有先后之分；若 F∼F(v₁,v₂)，则 1/F∼F(v₂,v₁)。若 T∼t(v)，则 T²∼F(1,v)。

取倒数就是把两个独立卡方项的位置互换。对 T 平方后，分子变成 Z²∼χ²(1)，仍和原分母独立，因此得到 F(1,v)。若需查密度，记 a=v₁/2、b=v₂/2、u=v₁x/v₂。正半轴的密度为 [Γ(a+b)/(Γ(a)Γ(b))]·(v₁/v₂)·ua−1·(1+u)−a−b。

对照教材中的 Γ 函数和 t 密度

Γ(a)=∫₀∞ ya−1e−ydy（a>0）。t(v) 密度为 [Γ((v+1)/2)/(√(vπ)Γ(v/2))]·(1+x²/v)−(v+1)/2。后续题通常按自由度查尾概率或分位数。

6.2.4 上侧 α 分位数

本教材定义上侧 α 分位数 c 满足 P(T>c)=α，即右侧尾部面积为 α。例如标准正态的上侧0.025分位数约为1.96。不同软件可能用左侧累计概率，因此查询时应确认表头；上侧0.025对应左侧0.975。

蓝色右尾面积为 α，c 是上侧 α 分位数；曲线仅为示意。

例3｜分位数的方向（新编）

Z∼N(0,1)，若上侧0.025分位数为1.96，求 P(−1.96≤Z≤1.96)。

由对称性，左侧 −1.96 以下也为0.025；从总概率1中去掉两侧。

答案：1−0.025−0.025=0.95。

两个上侧分位数 a 与 b 满足 a<b 时，中间面积是 P(T>a)−P(T>b)。标准正态和 t 关于零对称，可用 c1−α=−cα。χ² 与 F 没有这个对称性。F 取倒数时，右侧变左侧，因此 Fα(v₁,v₂)=1/F1−α(v₂,v₁)。离散分布的尾概率按格子跳跃，某些 α 下找不到严格等号的临界值。

正态总体的抽样分布（定理 6.2、6.3）

若 X₁,…,Xₙ 是正态总体 N(μ,σ²) 的独立样本，n≥2，则：

X̄∼N(μ,σ²/n)
(n−1)S²/σ²∼χ²(n−1)
(X̄−μ)/(S/√n)∼t(n−1)

并且 X̄ 与 S² 独立。这个精确结论依赖正态总体和独立样本；非正态时不能直接宣称精确服从 t 或 χ²。总体方差已知时，(X̄−μ)/(σ/√n) 服从标准正态。

例4｜选择抽样分布（新编）

从正态总体独立抽取16个观测值，总体标准差未知。对标准化后的量 (X̄−μ)/(S/√16)，给出分布。

题目满足正态总体和独立抽样，使用样本标准差 S 代替未知 σ，因此使用 t 分布，自由度为 n−1。

答案：该统计量服从 t(15)。

μ 在这里是总体真实均值。若 μ 未知，这个量含参数，仍可用它的已知分布反解 μ。

看清自由度和独立性从哪里来

把标准化后的 n 个观测看作一个向量。沿着 (1,…,1)/√n 作投影，得到第一坐标 Z=√n(X̄−μ)/σ；剩余 n−1 个相互垂直的方向都在离差和为零的空间内。正交变换保持联合标准正态密度 exp(−Σzᵢ²/2) 的乘积形式，因此变换后的坐标仍是独立标准正态。

剩余坐标平方和就是 Q=(n−1)S²/σ²。这给出 Q∼χ²(n−1)，也给出 Z 与 Q 独立。代入 Z/√(Q/(n−1)) 就得到 (X̄−μ)/(S/√n)∼t(n−1)。

自测由样本方差找到卡方自由度

独立正态样本的观测值为 2、4、6、8、10。均值 6，离差平方和 40，所以 S²=40/4=10，卡方自由度为 4。

两个独立正态总体的样本方差之比也可构造 F 统计量：(S₁²/σ₁²)/(S₂²/σ₂²)∼F(n₁−1,n₂−1)。 两个 σ² 可以不同，只需分别消去它们才能得到标准 F 分布。若两总体共享同一个未知方差 σ²，则两个离差平方和可合并估计它：

Sₚ²=[(n₁−1)S₁²+(n₂−1)S₂²]/(n₁+n₂−2)
[(X̄−Ȳ)−(μ₁−μ₂)]/[Sₚ√(1/n₁+1/n₂)]∼t(n₁+n₂−2)

两组均值差的标准差为 σ√(1/n₁+1/n₂)。两组的卡方量独立，合并后自由度相加，且仍与两组均值独立，因此采用上面的 t 分布。若总体非正态，样本均值在独立同分布、有限正方差、大样本时可用中心极限定理近似。需要多少观测取决于偏斜、尾部和所需精度。

本章回顾

  • 描述观测　先排序或数不超过界限的观测。经验分布每次跳高是该点的样本比例，方差单位为原单位平方。
  • 判断模型条件　独立同分布与有限方差给出均值的标准误 σ/√n。正态总体才保证本章的精确正态、χ²、t 与 F 抽样公式。
  • 检查自由度　正态观测用 μ 居中是 n，改用同一份样本的 X̄ 是 n−1。合并两组是 n₁+n₂−2，做方差比时保留分子、分母两个自由度的顺序。
  • 先写尾概率再查表　教材的 α 表示右侧面积；若工具使用左侧累计概率，输入 1−α。

自学检验：总体、样本与统计量怎样区分？

先自己想一想：某厂零件长度服从均值 μ 未知的分布。随机测得三个长度 9、10、11 mm，求样本均值和样本方差。

查看详细解答

总体是该厂所研究零件的长度分布；样本是按抽样规则得到的观测值。样本均值为 (9+10+11)/3=10 mm。通常定义的样本方差分母为 n−1：[(9−10)²+(10−10)²+(11−10)²]/2=1 mm²。总体均值 μ 是未知参数；样本均值是由样本算出的统计量。
