18.2 量子信息科学的基本概念

本节目录
  • 一、经典比特与量子比特
  • 二、不可克隆定理
  • 三、四个贝尔态

一、经典比特与量子比特

经典比特在一个确定时刻取 0 或 1。纯态量子比特可写 |ψ⟩=α|0⟩+β|1⟩，α、β 为复概率幅，满足 |α|²+|β|²=1。计算基测量得到 0 的概率是 |α|²、得到 1 的概率是 |β|²。叠加不是“一次测量同时读出 0 和 1”；相对相位会影响其他基下的测量结果。

n 个量子比特的状态空间维数是 2ⁿ，但不能据此声称一次测量就能直接读出 2ⁿ 个复振幅。真实系统还可能处于混合态，需用密度算符描述。

二、不可克隆定理

不存在一个固定的物理过程，能对所有未知量子态都制作完美副本，同时保留原态。证明思路：假设同一装置分别把非正交态 |a⟩、|b⟩ 复制，且所有辅助系统按相同要求工作。保持内积的幺正演化要求 s=s²，其中 s=⟨a|b⟩；但非正交且不相同的态有 0<|s|<1，与 s=s² 矛盾。

已知的一组正交态可以被特定装置区分并复制；定理限制的是对任意未知态的通用完美复制，不是说任何量子信息都无法以其他形式传递。

三、四个贝尔态

|Φ±⟩=(|00⟩±|11⟩)/√2
|Ψ±⟩=(|01⟩±|10⟩)/√2

四态相互正交，可构成两个量子比特空间的一组基。仅看单方测量无法辨认是哪一个贝尔态；两方的关联和测量基都重要。

例1｜测量概率与相位（新编）

一个量子比特 |ψ⟩=(|0⟩−|1⟩)/√2，分别求计算基下结果 0 和 1 的概率。

两个概率幅大小均为 1/√2，负号影响相对相位，但不改变该基下的模平方。

答案：P(0)=1/2，P(1)=1/2。

改用其他测量基时，这个相对负号可能改变结果。
