18.2 量子信息科学的基本概念

本节目录

  • 二、不可克隆定理
  • 三、四个贝尔态

一、经典比特与量子比特

经典比特在一个确定时刻取 0 或 1。纯态量子比特可写 |ψ⟩=α|0⟩+β|1⟩，α、β 为复概率幅，满足 |α|²+|β|²=1。计算基测量得到 0 的概率是 |α|²、得到 1 的概率是 |β|²。叠加不是“一次测量同时读出 0 和 1”；相对相位会影响其他基下的测量结果。

n 个量子比特的状态空间维数是 2ⁿ，但不能据此声称一次测量就能直接读出 2ⁿ 个复振幅。真实系统还可能处于混合态，需用密度算符描述。

二、不可克隆定理

不存在一个固定的物理过程，能对所有未知量子态都制作完美副本，同时保留原态。证明思路：假设同一装置分别把非正交态 |a⟩、|b⟩ 复制，且所有辅助系统按相同要求工作。保持内积的幺正演化要求 s=s²，其中 s=⟨a|b⟩；但非正交且不相同的态有 0<|s|<1，与 s=s² 矛盾。

已知的一组正交态可以被特定装置区分并复制；定理限制的是对任意未知态的通用完美复制，不是说任何量子信息都无法以其他形式传递。

三、四个贝尔态

|Φ±⟩=(|00⟩±|11⟩)/√2
|Ψ±⟩=(|01⟩±|10⟩)/√2

四态相互正交，可构成两个量子比特空间的一组基。仅看单方测量无法辨认是哪一个贝尔态；两方的关联和测量基都重要。

例1｜测量概率与相位（新编）

一个量子比特 |ψ⟩=(|0⟩−|1⟩)/√2，分别求计算基下结果 0 和 1 的概率。

两个概率幅大小均为 1/√2，负号影响相对相位，但不改变该基下的模平方。

答案：P(0)=1/2，P(1)=1/2。

改用其他测量基时，这个相对负号可能改变结果。

量子态的四个常用计算步骤

第一步写出计算基：一个比特用 |0⟩、|1⟩，两个比特依次用 |00⟩、|01⟩、|10⟩、|11⟩。第二步给每个基态写振幅；第三步检查所有振幅的模平方和为 1；第四步根据实际测量的比特和基底求概率。

新编例题：|ψ⟩＝√(3/5)|00⟩＋√(2/5)|11⟩。两比特同时按计算基测量，00 的概率为 3/5、11 的概率为 2/5，另外两种为零。若只测第一个比特，第一个结果为 0 的概率也是 3/5；结果为 1 的概率是 2/5。

概率幅与概率不同，两个可相干的路径到达同一个最终态时，应先加振幅再取模平方。复制任意未知量子态受到不可克隆定理限制，但已知的正交基态可以在适当操作下复制；不能把“不可以克隆任意未知态”误说成“任何量子信息都不能重复”。

详细讲解与练习

经典比特与量子比特

经典比特在读取时表示 0 或 1。一个理想量子比特的纯态可以写作 |ψ⟩=α|0⟩+β|1⟩，其中 α、β 一般为复数，且 |α|²+|β|²=1。|0⟩ 和 |1⟩ 是选定测量基下的两个基态；α、β 称为概率幅，不是概率本身。

如果沿这个计算基测量，得到 0 的概率是 |α|²，得到 1 的概率是 |β|²。理想的投影测量后，态相应变为与结果对应的基态；其他测量模型及噪声情形需要另行描述。

例 1：|ψ⟩=(√3/2)|0⟩+(1/2)|1⟩。测得 0 的概率为 3/4，测得 1 的概率为 1/4，两者相加为 1。不能把幅度 1/2 当成结果 1 的概率。

叠加与经典随机混合不同

叠加态的幅度有相位，后续操作中不同路径的概率幅可以干涉；经典随机混合则以经典概率随机选择状态，不能无条件表现出相同干涉。要区分两者，需要指定制备方式和测量方式；仅看某一个测量基下的 0、1 统计结果，有时无法区分。

整体乘以同一个不可观测的全局相位不会改变单个纯态的测量概率；分量之间的相对相位可以影响在其他基下的测量。讨论“相位”时要区分这两种情况。
