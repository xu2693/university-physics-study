19.5 半导体

本节目录
  • 一、本征和掺杂
  • 二、PN 结
  • 三、光生伏打效应

一、本征和掺杂

本征半导体中，热或光激发可把价带电子提升到导带，留下空穴；电子和空穴都可参与电流。空穴是描述价带空态的有效载流子，表现出正电荷响应，不是原子核从晶格中飞走。

对硅等材料，施主掺杂可提供较多导带电子，形成 n 型；受主掺杂可产生较多空穴，形成 p 型。n、p 指多数载流子类型，不表示整块材料必然带负净电或正净电；在普通电中性条件下，电离杂质电荷也要计入。

二、PN 结

p、n 两区接触后，多数载流子因浓度差扩散，界面附近留下离化杂质，形成耗尽区和内建电场。平衡时扩散与漂移电流相抵，净电流为零，并非每一种载流子都不运动。正向偏置通常降低有效势垒、增加电流；反向偏置通常加宽耗尽区、产生较小反向电流，足够高反向电压可发生击穿。实际器件电流还受温度和制造工艺影响。

三、光生伏打效应

光子被吸收后可激发电子–空穴对；PN 结附近的内建电场有助于分离载流子，形成可用的电势差和电流。太阳能电池利用这一过程，但光能转化效率受复合、光谱、温度和器件结构等多种因素限制。

例1｜载流子类型（新编）

硅中适量掺入施主杂质后形成 n 型半导体，判断多数载流子及整体是否一定带负电。

施主提供易于进入导带的电子，故电子为多数载流子；离化施主等电荷需一并计入整体电中性。

答案：多数载流子是电子；整体不一定带负净电。

电子、空穴与 PN 结

本征半导体受热或光照时，电子可从价带跃迁到导带，价带中留下空穴。空穴是便于描述的等效正电载流子，并不是一个从原子中飞出的新基本粒子。本征材料中，理想情况下产生的电子和空穴数量相等；掺杂后多数载流子的类型取决于杂质和电离情况。

n 型半导体以电子为多数载流子，p 型以空穴为多数载流子；材料整体通常近似电中性，并不意味着 n 型整块带负电、p 型整块带正电。两者接触后，载流子扩散和结区电场相互制约，在平衡时形成耗尽区与内建电势差。

判断方向：通常 PN 结正向偏置指 p 侧接电源正极、n 侧接负极，外加电压降低结区势垒，电流较易通过；反向偏置通常增大势垒，电流较小。实际器件还存在漏电、温度效应和击穿，不能把“反向电流很小”绝对化为永远等于零。

例题与重点理解

六点一、光生伏打效应

光照到半导体时，若光子能量足以促成合适的电子跃迁，就可能产生电子—空穴对。在 p-n 结附近，内建电场可使电子和空穴向不同方向分离；这种分离使器件两端出现光生电压，外接闭合电路时可以输出电流。

光伏器件把一部分光能转换为电能，不是凭空产生能量。实际转换效率取决于吸收、复合、材料、结构、温度和外部电路等因素，不能说每个入射光子都一定变成可利用电能。光伏效应与第 16 章中的外光电效应相关，但讨论对象不同：太阳能电池主要利用半导体内部载流子的产生、分离与输运，不要求电子从材料表面逸出到真空。

详细讲解与练习

半导体中的电子与空穴

本征半导体在热激发等作用下，电子可以从价带进入导带，同时在价带留下空态。适当条件下，可把价带中参与输运的空态描述为带正电的准粒子——空穴。空穴不是原子核实际移动形成的洞，而是对电子集体行为的有效描述。

掺入适当杂质可改变载流子浓度。常见 n 型半导体以电子为多数载流子，p 型以空穴为多数载流子；多数载流子不意味着另一种载流子完全不存在。材料整体在常见情况下仍近似电中性，不能把 n 型误解成整块材料带大量净负电荷。

自测与解答

1. 分子势能曲线在某处斜率为零，能否立即断定稳定平衡？

解：不能。还要看附近是否为局部极小值；极大值也可能斜率为零。

2. n 型半导体中是否绝对没有空穴？

解：不是。n 型通常指电子为多数载流子，空穴仍可能存在。

3. 理想简谐振子从 v=1 到 v=2，能级差是多少？

解：E₂−E₁=[(2+1/2)−(1+1/2)]ℏω=ℏω。

4. 是否只要材料电阻接近零，就可以忽略所有超导态条件？

解：不能。超导态还有磁响应等特征，并受温度、磁场和电流等条件限制。

本征半导体和空穴

本征半导体中，价带电子可因热激发等进入导带，同时留下空态。用空穴描述价带中相关电子的集体输运时，它表现为带正电的有效载流子。电子与空穴可以分别对电流有贡献。

在理想本征半导体热平衡模型中，电子和空穴浓度相等，常记 n=p=nᵢ。载流子浓度依赖温度与材料；真实材料还会受到杂质、缺陷和非平衡激发影响。

掺杂与多数载流子

向半导体加入适当的施主杂质，可形成 n 型材料，多数载流子通常为电子；受主杂质形成的 p 型材料多数载流子通常为空穴。多数不意味着少数载流子完全消失。掺杂后材料通常仍近似电中性，因为离化杂质和载流子等电荷共同满足整体平衡。

在简单非简并热平衡模型下，有质量作用关系 np=nᵢ²；这不是任何强掺杂、强非平衡条件下都能无条件照搬的公式。

例 2：在符合上述模型的条件下，nᵢ=10¹⁰ cm⁻³，某 n 型样品平衡电子浓度 n=10¹⁵ cm⁻³，则空穴浓度 p=nᵢ²/n=10⁵ cm⁻³。单位需统一；该数值仅为演示，不代表所有温度和材料。

p-n 结的基本图像

p 型和 n 型区域接触后，载流子因浓度差发生扩散；靠近界面形成空间电荷区与内建电场。在热平衡时，扩散与漂移电流达到平衡，总电流为零，并不是所有载流子停止运动。

外加电压会改变势垒和载流子输运，使理想二极管表现出整流特性。正向和反向偏置的电流大小取决于材料、温度及实际器件，不应认为真实反向电流在所有条件下绝对为零；高反向电压还可能导致击穿。

练习与解答

1. 一块 n 型半导体是否一定整体带负电？

解：不一定。n 型主要表示电子为多数载流子；离化杂质等电荷参与平衡，宏观上通常近似电中性。

2. 已知某热平衡态 E=μ，T>0，求 f(E)。

解：e⁰=1，因此 f(E)=1/2。它是所讨论单粒子态的占据概率。

3. 若符合非简并热平衡模型，nᵢ=2×10¹⁰ cm⁻³，n=4×10¹⁵ cm⁻³，求 p。

解：p=nᵢ²/n=(4×10²⁰)/(4×10¹⁵)=10⁵ cm⁻³。

4. p-n 结热平衡时总电流为零，是否意味着所有载流子完全静止？

解：不是。扩散和漂移等贡献在平衡时相互抵消，微观热运动仍存在。
