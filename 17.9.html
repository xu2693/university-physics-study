17.9 全同粒子、多电子原子和元素周期表

上一节数出了一个电子可用的量子态。这一节回答两个新问题：多个电子能否随意挤进同一个态？为什么原子的性质会周期性重复？路线是“交换对称性 → 泡利原理 → 容量 → 实际组态”。

一、全同性与交换对称性

两个电子的质量、电荷、自旋等内禀性质完全相同，叫全同粒子。在波函数发生重叠的量子描述中，不能给电子贴上可观测的永久编号，再把“谁到哪里”当成额外物理信息。写1、2只是标记波函数的变量位置，不是给电子创造两种身份。

令 qᵢ=(rᵢ,σᵢ)，包含第 i 个变量的位置和自旋。交换算符 P̂₁₂ 的作用为 P̂₁₂Φ(q₁,q₂)=Φ(q₂,q₁)。交换两次回到原态，所以 P̂₁₂²=I。若态具有确定的交换性质，P̂₁₂Φ=λΦ，则 λ²=1，得到 λ=+1 或 −1：

对称态：Φ(q₂,q₁)=+Φ(q₁,q₂)，
反对称态：Φ(q₂,q₁)=−Φ(q₁,q₂)。

在本书讨论的普通三维粒子体系中，整数自旋的玻色子使用对称总态，半整数自旋的费米子使用反对称总态。电子自旋为1/2，是费米子。交换两次只能说明本征值为±1，并不能单凭这一步证明哪种自旋对应哪个符号；自旋与统计的联系是另一个物理结论。

反对称态多出的整体负号不改变 |Φ|²。物理差别在于把单粒子振幅相加时必须怎样组合，由此改变干涉、相关性和允许态。不能因为最后概率不变，就把反对称要求删掉。粒子相距很远、态重叠可忽略时，有时可近似像可区分粒子一样处理，但电子仍是全同费米子。

二、从两个电子的态推到泡利原理

取两个正交归一的完整单粒子态 a(q)、b(q)，其中已经包括自旋。简单乘积 a(q₁)b(q₂) 通常没有所需交换性质。应组合为：

Φ₊=[a(q₁)b(q₂)+b(q₁)a(q₂)]/√2，
Φ₋=[a(q₁)b(q₂)−b(q₁)a(q₂)]/√2。

交换 q₁、q₂，前者不变，后者变号。归一化时，两个直接项各积分为1，交叉项含 ⟨a|b⟩⟨b|a⟩=0，故除以 √2 后范数为1。这个系数依赖 a、b 正交；不能把同一个函数代入玻色式后还沿用该归一化系数。

对电子，必须取 Φ₋。若想让两个电子处于同一个完整态，令 b=a，分子恰好相消，Φ₋≡0；零函数无法归一化，因而不是可用物理态。这就是泡利不相容原理：两个全同费米子不能占据同一个完整单粒子态。在原子的独立电子近似中，表现为不能有两电子的 (n,l,m,mₛ) 全部相同。

为什么同一空间轨道还可以放两个电子？

空间函数相同不等于完整态相同。取 a(q)=φ(r)χ₊(σ)、b(q)=φ(r)χ₋(σ)，因两种自旋正交，a、b 仍为不同完整态。电子总态为：

Φ=φ(r₁)φ(r₂)
×[χ₊(σ₁)χ₋(σ₂)−χ₋(σ₁)χ₊(σ₂)]/√2。

空间部分对称，自旋部分反对称，乘积才是反对称。这里两个电子的自旋总态是单重态；不能说“电子的空间波函数永远必须反对称”。更一般地，空间对称与自旋反对称，或空间反对称与自旋对称，均可给反对称总态。只交换空间而不交换自旋也不是本节的完整粒子交换。

多个电子时可把正交自旋轨道排成斯莱特行列式，除以 √(N!)。交换两个电子对应交换两行，行列式变号；两个完整态相同则两列相同、行列式为0。它把上面的两电子论证推广到 N 个电子。

三、先数容量：三种问题不能混在一起

在中心场的单电子轨道近似中，空间轨道用 n,l,m 标记。每一空间轨道有两种自旋投影，最多容纳2电子。给定 n,l 的支壳层有 2l+1 个 m，所以容量为：

Nₙₗ=2(2l+1)，
Nₙ=Σₗ₌₀n−12(2l+1)=2n²。

求和可这样检查：前 n 个奇数之和为 n²，再乘两种自旋。n=1,2,3,4 的主壳层通常叫 K、L、M、N，容量分别2、8、18、32；s、p、d、f 支壳层容量分别2、6、10、14。

保留的新编例｜p支壳层和n=2主壳层

p 对应 l=1，允许 m=−1,0,1，三个空间轨道，每个最多2电子，所以 p 支壳层最多6电子。n=2 时包含 2s 与2p，容量为2+6=8。一个p轨道是2个，一个p支壳层是6个，n=2整个壳层是8个，题目对象决定该用哪个数。

“可容纳”只是允许态的最大计数，不表示一个中性原子的基态必先把第 n 层填满才使用 n+1 层。第三主壳层容量18，但第三周期只有8个元素，原因要看下面的能量次序。

四、容量之外，还必须考虑能量

对固定的电荷 Ze 原子核，非相对论多电子哈密顿量还包含电子间排斥：

Ĥ=Σᵢ[−ℏ²∇ᵢ²/(2mₑ)−Zκ/rᵢ]
+Σᵢ<ⱼ κ/|rᵢ−rⱼ|。

最后一项把电子联系起来，精确态通常不能拆成独立的氢原子函数。教材用中心场近似谈单电子轨道：其他电子的平均作用导致屏蔽，不同 l 的电子对核的穿透不同，因此能量一般不再只由 n 决定。这里的 (n,l,m,mₛ) 是有用的近似轨道标记，并非任意精确相互作用本征态都能给每个电子永久分配四个量子数。

写基态组态时，按以下顺序理解规则：

  1. 泡利原理：先排除违反同态不相容的方案。
  2. 能量最低：在允许方案中选择体系总能量较低者，不是把所有电子都塞进1s。
  3. 洪特规则的本节用法：在同一支壳层的简并轨道中，通常先分别单占、取平行自旋，再配对。它涉及交换作用和总能量，不是要求所有壳层的电子都自旋平行。

教材以 n+0.7l 的大小作外层轨道能序的经验估计：值较小者通常先填。于是常用次序为：

1s → 2s → 2p → 3s → 3p → 4s → 3d
→ 4p → 5s → 4d → 5p → 6s → 4f → …

例如3d给3+0.7×2=4.4，4s给4，因此构造K、Ca基态时先用4s。经验次序不等于恒定的精确能级表：轨道能量会随元素、电荷态、占据情况改变，复杂元素有例外；也不能把“中性原子先填4s”直接当成“任何离子都先失去3d”的依据。

新编例｜碳的两个2p电子为什么先分开放？

碳有6电子，1s²2s²已占4个，余2个进入2p。画三格分别代表三个简并p轨道，常用基态示意：

2p²： [ ↑ ]　[ ↑ ]　[　 ]

它既满足泡利又符合此处洪特规则。写成 [↑↓][　][　] 没违反泡利，但通常不是这个组态中的最低能排列。氮2p³可画 [↑][↑][↑]；氧2p⁴再配对为 [↑↓][↑][↑]。方格不是电子轨道照片，具体哪一格先占并无优先地位；箭头图也不保证已经构造好所有总角动量的精确本征态。

六、自测与回顾

1．两个电子空间位置相同，是否必定违反泡利？

不是。泡利禁止占据同一个完整单粒子态，并非禁止位置测量在同一空间区域。反向自旋的电子可以占同一空间轨道。相同自旋分量的反对称空间振幅在重合位置为0，不能把这一特例扩大成“所有电子永不靠近”。

2．3d支壳层和n=3主壳层分别最多多少电子？

3d：l=2，2(2l+1)=10。n=3：3s、3p、3d合计2+6+10=18。第三周期长度8与主壳层容量18不是同一问题。

3．泡利原理能否单独确定碳的基态排布？

不能。泡利给允许性，选择最低能组态还需能量信息；同支壳层的自旋排布还需考虑洪特规则。把1s写为3电子则首先违反泡利，无须再比较能量。

4．交换对称性究竟检查空间部分还是总态？

总态，包括位置和自旋。对电子要求总态反对称。空间部分对称时应与反对称自旋部分组合，反之亦然。

做题步骤：先认粒子种类及完整态，再看交换符号；数容量时明确轨道/支壳层/主壳层；写组态时再用能量和洪特规则；最后把上标电子数加起来，检查是否等于题给总电子数。下一节用微扰理论处理可解模型上附加的小作用。
