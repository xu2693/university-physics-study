对应教材下册第 103—108 页。先画出电流、磁场和受力方向，再计算大小。μ₀ 取 4π×10⁻⁷ H/m 的常用近似。以下为独立学习解法；图中缺少的方向、材料或简化条件应与教材对照。

12-1 两电源电路

以 b 为零电势，a 的电势记为 V。先假设左、右支路的电流均流入 a，中央支路流出。两电源正极都在上，支路总电阻分别为 10+3=13 Ω 和 0.5+1.5=2 Ω，故节点方程

(12−V)/13+(8−V)/2=V/4，解得 V=256/43≈5.953 V。

代回得 I₁≈0.465 A（向右）；右支路实际流向 a 的电流约 1.023 A；中央支路 I₃≈1.488 A（向下）。按原图 I₂ 向右为正，I₂≈−1.023 A，负号表示实际方向相反。

检查：两侧流入之和等于中央流出，0.465+1.023≈1.488 A；电流与电阻的乘积具有电压单位。

12-2 两导线接到均匀圆环

圆环粗细均匀，两段圆弧电阻分别与弧长、圆心角成正比；两段电压相同，分流电流与电阻成反比，所以两段的“电流×圆心角”相等。圆弧在圆心的磁场大小正比于此乘积，而两段电流绕圆心方向相反，磁场相互抵消。径向引线的电流元与指向圆心的连线平行，也不贡献磁场，按细导线电流模型得到 B=0。

原题文字称“铁环”：若计入真实铁磁材料的磁化，题目未给磁化状态和材料性质，不能仅凭自由电流模型保证这一结论；上面的结果采用通常的细导线近似。

12-3 相互垂直的圆线圈

每个 N 匝圆线圈在圆心的磁场大小 B=μ₀NI/(2R)。半径先换为米：

B₁=(4π×10⁻⁷)×10×10/(2×0.20)=3.14×10⁻⁴ T；B₂=(4π×10⁻⁷)×20×5/(2×0.10)=6.28×10⁻⁴ T。

两线圈平面垂直，所以两场方向沿各自法线且互相垂直。矢量相加得 B=√(B₁²+B₂²)≈7.02×10⁻⁴ T，与 B₁ 的夹角 arctan(B₂/B₁)=arctan 2≈63.4°。具体空间指向还须由每个线圈的电流绕向和右手定则确定；仅给大小时不能凭空指定方向。

12-4 圆环与切线直导线

圆环电流顺时针，圆心磁场向纸内，大小 B环=μ₀I/(2R)；直导线电流向右，圆心在其上方，右手定则给 B直=μ₀I/(2πR)，方向向纸外。两场反向，且 B环/B直=π，因此相减得 B=μ₀I(π−1)/(2πR)，方向垂直纸面向里。相切处仅无限接近，并不接触短接。

12-5 三角形框与引线

电阻均匀，a→b 直边电阻为 R，a→c→b 两边总电阻为 2R。两支路电压相同，电流分别为 2I/3 和 I/3。三边到中心距离都为 l/(2√3)，每边端点所对角度也相同，因此单边在中心的磁场大小与该边电流成正比。直边磁场方向与另外两边相反，而 2I/3=I/3+I/3，三边恰好抵消。

引线 1 所在直线经过 O，电流元与指向 O 的连线平行，贡献为零。引线 2 从 b 水平向右延伸，O 到引线距离 h=l/√3，垂足恰在 b；半无限直线场 B=μ₀I/(4πh)，因此 B=√3μ₀I/(4πl)，按图中电流方向垂直纸面向里。图示引线应按半无限长模型处理。

12-6 无限长薄板旁的磁场

把宽度为 l 的薄板沿 x 方向切成平行无限长细条。均匀分布时，宽 dx 的细条电流 dI=(I/l)dx；以板左边为 x=0，P 距该条 d+l−x。各条在 P 的磁场方向相同，所以

B=∫₀ˡ μ₀(I/l)dx/[2π(d+l−x)]=[μ₀I/(2πl)]ln[(d+l)/d]。

图中电流沿 +y，P 在板右侧，磁场沿 −z，即垂直纸面向里。对数内是长度之比；当 d≫l 时，ln(1+l/d)≈l/d，退化为无限长细导线结果 μ₀I/(2πd)。

12-7 带电刚性回路转动

回路由半径 a、b（b>a）的两个半圆弧和两段径向连接段组成，电荷随整个刚体转动。对电荷元 dq=λ dl，其速度大小为 |ω|r，方向垂直半径。按低速、准静态近似，它在圆心产生 dB=μ₀|λω|dl/(4πr)，各部分方向沿同一转轴。

半圆上 dl/r=dθ，两段各贡献 π；连接段上 dl=dr，两段各贡献 ln(b/a)。因此 B=μ₀|λω|[π+ln(b/a)]/(2π)。径向线段虽然沿半径排列，电荷却随刚体沿切向运动，不能漏掉它们。方向由电荷符号和转动方向共同决定。

12-8 半圆柱面电流

把半圆柱面按角度分成平行的无限长细导线。电流沿柱面均匀分布，故 dI=(I/π)dθ；每条到轴线距离均为 R，贡献大小 dB=μ₀dI/(2πR)。以半圆对称轴为基准，成对细条的一个磁场分量抵消，另一个相加；对应的角积分为 ∫₋π/₂^π/₂ cosθ dθ=2。

故轴线上磁场大小 B=μ₀I/(π²R)，方向在横截面内，可对任意一对对称细条用右手定则判断。单位 μ₀I/R 为 T；相对于同一总电流的单根直线，系数小于 1/(2π)，符合部分分量相互抵消的情况。

12-9 密绕平面螺旋线圈

半径从 R₁ 到 R₂ 的径向宽度中均匀分布 N 匝，所以半径 r 附近宽 dr 中的匝数 dN=N dr/(R₂−R₁)。密绕时近似将这些匝看作同心圆，每匝在圆心产生 μ₀I/(2r)，故

B=∫R₁R₂ μ₀I dN/(2r)=[μ₀NI/(2(R₂−R₁))]ln(R₂/R₁)。

方向垂直线圈平面，由电流绕向确定。当 R₂ 趋近 R₁=R 时，对数与宽度之比趋近 1/R，结果回到 N 匝半径 R 圆线圈的中心场。

12-10 两个反向转动的带电圆环面

半径 r、宽 dr 的圆环电量 dq=σ2πr dr，转速为 n 时产生电流 dI=n dq；圆心 dB=μ₀dI/(2r)=μ₀πσn dr。按图内环覆盖 R₁ 到 R₂、外环覆盖 R₂ 到 R₃，转向相反，令两磁场大小相等：n₁/n₂=(R₃−R₂)/(R₂−R₁)。

12-11 半球密绕线圈

设 θ 为圆环所在位置相对轴线的极角。该环半径 R sinθ，环心到球心的轴向距离 R cosθ，圆环轴线场公式给每匝在球心的场为 μ₀I sin²θ/(2R)。

沿四分之一圆弧均匀密绕共 N 匝，dN=(2N/π)dθ。将 θ 从 0 积到 π/2，并用 ∫sin²θ dθ=π/4，得 B=μ₀NI/(4R)，方向沿公共轴线，用右手定则判定。这里的均匀指沿圆弧的匝数均匀，不是沿轴向均匀。

12-12 两根反向电流导线

两导线电流反向，线间磁场都指向纸内。在中点，每线距离 0.20 m，所以 B=2μ₀I/(2π×0.20)=4.00×10⁻⁴ T，方向垂直纸面向里。

取纸内为正法线，左导线为 x=0、右导线为 x=0.40 m。阴影区域高 l=0.25 m，横向从 x=0.10 到 0.30 m，窄条面积 dS=l dx，因此

Φ=l∫₀.₁₀⁰.³⁰ [μ₀I/(2π)][1/x+1/(0.40−x)]dx=μ₀Il ln3/π≈2.20×10⁻⁵ Wb。

两项积分各给 ln3。若法线改为纸外，磁通量为负；不可用中点场乘面积代替非均匀场积分。

12-13 导体圆柱内部的磁通

电流在圆截面均匀分布，半径 r 内的电流 I内=I r²/R²。取半径 r 的同轴圆为安培环路，B·2πr=μ₀I内，所以 B(r)=μ₀Ir/(2πR²)。

所求为图示从轴线延伸到圆柱表面、长 l 宽 R 的径向开曲面，磁场垂直这个面。选与磁场同向的法线，分成面积 l dr 的窄条，得到 Φ=l∫₀ᴿB(r)dr=μ₀Il/(4π)。反向法线给负值。虽然结果不含 R，但推导中电流密度随 R 改变；这里的电流 I 固定。

12-14 同轴圆柱筒

两筒间 R₁<r<R₂ 取与轴线垂直的同轴圆形安培环路。包围内筒电流 I，外筒回流在环路之外；由圆柱对称性，B·2πr=μ₀I，因此 B=μ₀I/(2πr)，方向环绕轴线。

图中径向截面长 l，取法线与当地磁场同向，磁通量 Φ=l∫R₁R₂B(r)dr=μ₀Il ln(R₂/R₁)/(2π)。若环路位于外筒之外，包围的去程与回程电流抵消，结合理想圆柱对称性，外场为零。

12-15 螺线环

理想密绕环内半径 r 处，安培环路定理 B·2πr=μ₀NI，故 B(r)=μ₀NI/(2πr)，D₁/2<r<D₂/2。截面高为 h，积分 Φ=∫B h dr=[μ₀NIh/(2π)]ln(D₂/D₁)。理想模型忽略漏磁和绕线离散性。

12-16 无限长圆柱面环向电流

面电流密度 jₘ 就是每单位轴长绕行的电流，等效无限长理想螺线管。轴线上 B=μ₀jₘ，方向由电流绕向按右手定则确定。该结果与半径无关，依赖无限长和均匀面电流条件。

12-17 无限大载流厚板

板平行 xz 平面，中心 y=0、厚度 2d，均匀电流密度 j 沿 +z。对称性使磁场沿 x 轴，两侧反向；在 y>0 一侧，+z 方向电流的右手定则给场沿 −x。

取跨越中心面的矩形环路，两条长边长度 l，位于 y 和 −y。|y|≤d 时，穿过环路电流为 j·2|y|l，故 2Bl=μ₀j·2|y|l，B=μ₀j|y|。板外时，包围厚度固定为 2d，B=μ₀jd。

用矢量统一写：B⃗=−μ₀jy î（|y|≤d）；y>d 时 B⃗=−μ₀jd î；y<−d 时 B⃗=+μ₀jd î。在两边界连续；j 的单位 A/m²，乘 μ₀ 和长度后为 T。

12-18 导线接到均匀环

图中短弧圆心角 120°，长弧 240°，电阻比 1:2，故电流分配为短弧 2I/3、长弧 I/3。图中的环路 L 只套住右侧短弧一次，因此对磁场强度 H 应用安培定理得 ∮L H·dl=±2I/3，正负由环路方向及右手法线决定。题目称环为铁环：B 的环流还受到铁磁材料磁化的影响，未给材料磁化状态时，不能直接把它确定为 μ₀ 乘以自由电流。若明确忽略磁化、按真空电流模型近似，才有 ∮L B·dl≈±2μ₀I/3。不要把总电流 I 当成 L 包围的短弧电流。

12-19 可转动 U 形导线

两侧边各长 a、底边长 a，单位长度质量 ρS。关于 OO′ 轴，重力矩大小为两侧边各 ρSag·(a/2)sinα，加上底边 ρSag·a sinα，总计 2ρSga²sinα。磁力矩大小 I a² B cosα。平衡得 B=2ρSg tanα/I。假设导线截面均匀、轴上的连接段不贡献力矩。

12-20 导轨电流与能量

按题目的理想半无限导轨模型，两条导轨在滑动物体上的磁场沿轨距积分，得到 F=[μ₀I²/(2π)]ln[(d+r)/r]。取题给 r=0.025 m、d=0.10 m，且理想情况下电流与推力恒定、忽略损耗，令 FL=33 MJ，得到 I≈2.26×10⁶ A。这是题设模型的数量级计算，实际装置的能量损耗、导轨与电源条件并不包含在内。

12-21 直导线旁的圆形电流回路

必须有 d>R，圆环不与长直导线相交。取导线沿 y 轴、圆心为 (d,0)，按图顺时针电流。用角 θ 参数化圆周，x=d+Rcosθ，磁场 Bz=−μ₀I₁/[2π(d+Rcosθ)]。由 dF=I₂dl×B，竖直分量成对抵消，水平合力为

Fₓ=[μ₀I₁I₂/(2π)]∫₀²π Rcosθ/(d+Rcosθ)dθ。

将被积式写成 1−d/(d+Rcosθ)，并用 ∫₀²πdθ/(d+Rcosθ)=2π/√(d²−R²)，得 Fₓ=μ₀I₁I₂[1−d/√(d²−R²)]<0。

因此合力大小 F=μ₀I₁I₂[d/√(d²−R²)−1]，指向直导线。近侧电流与长导线同向，吸引大于远侧排斥，方向与积分一致。d≫R 时 F≈μ₀I₁I₂R²/(2d²)。

12-22 磁场中的圆环张力

图示方向使每段导线受到径向向外的磁力。取小弧对应角 dθ，磁力大小 IB R dθ，两端张力指向圆心的合分量约 T dθ，故 T=IBR=0.010 N。假定磁场均匀、圆环细且处于静力平衡；若电流或磁场反向，径向力朝内，单凭电流不能推定同样的拉张力。

12-23 直导线下方矩形线框

上边必须与直导线电流同向才能被吸引向上：图中上边电流向右，因此线框电流顺时针。上边距导线 d、下边距 d+a，左右边的水平力抵消。向上净磁力 F=μ₀I₁I₂b[1/d−1/(d+a)]/(2π)，给定图示位置时，可平衡的重量上限等于此值。

12-24 薄金属板旁的矩形线圈

若板上电流在宽度 a 内均匀，板边外距离 x 处的场为 B(x)=μ₀I₁ ln[(x+a)/x]/(2πa)。设 MN、PQ 的长度为 L，分别距板边 b 与 b+c，则 F_MN=I₂L B(b)，朝向金属板；F_PQ=I₂L B(b+c)，背离金属板。若未知电流横向分布或边长 L，就不能仅凭总电流写出唯一数值；两边合力方向指向板。

12-25 旋转带电圆盘的磁力矩

半径 r、宽 dr 的环带 dq=σ2πr dr，旋转周期 2π/ω，等效电流 dI=σωr dr。环的磁矩 dμ=dI·πr²，积分 0 到 R：μ=πσωR⁴/4。磁矩与外场垂直，故力矩大小 τ=π|σω|R⁴B/4。方向由 μ⃗×B⃗ 判断。

12-26 方形线圈磁矩

每匝面积 (0.150 m)²=0.0225 m²。磁矩 μ=NIS=200×0.8×0.0225=3.60 A·m²；最大力矩 τ最大=μB=14.4 N·m，发生在线圈磁矩垂直磁场时。

12-27 电子的经典旋转模型

设球壳总电荷为 q，均匀面密度为 q/(4πR²)。极角 θ 到 θ+dθ 的纬圈带电 dq=(q/2)sinθ dθ，转动周期为 2π/ω，等效电流 dI=ωdq/(2π)。纬圈面积 πR²sin²θ，因此 dμ=dI·πR²sin²θ。积分 0≤θ≤π，利用 ∫sin³θ dθ=4/3，得到 μ=qωR²/3，带符号的轴向方向由电荷和旋转方向决定。

由大小关系 v=|ω|R=3|μ|/(|e|R)，取题给 R=10⁻¹⁸ m、|μ|=0.928×10⁻²³ J/T，得 v≈1.74×10¹⁴ m/s，远大于光速。半径更小，所需速度更大，故经典刚性球壳模型不成立。这里是在检验假设模型，不是断言电子实际有这样的表面旋转。

12-28 地磁场中的电子

取东、北、上分别为 x、y、z 正方向。速度向北、磁场向下，正电荷的 v×B 指西；电子电荷为负，因此初始磁力及偏转方向向东。

按教材的非相对论近似，K=1.2×10⁴ eV=1.92×10⁻¹⁵ J，v=√(2K/m)≈6.50×10⁷ m/s。加速度 a=|e|vB/m≈6.28×10¹⁴ m/s²，半径 R=mv/(|e|B)≈6.72 m。

“南北方向飞经20 cm”给的是向北的位移，不是弧长。圆弧几何给向东偏移 Δx=R−√(R²−0.20²)=0.20²/[R+√(R²−0.20²)]≈2.98 mm。有理化后的计算可减少两个接近数相减的误差。

12 keV 约为电子静能的2.35%，经典近似已有可见误差。若用 γ=1+K/(mc²)、p=γmv，得到 v≈6.39×10⁷ m/s、R≈6.76 m、横向加速度约6.03×10¹⁴ m/s²、偏移约2.96 mm。两组是不同精度模型，不能交叉混用。

12-29 质谱仪

在同一电荷量、每条谱线对应一种同位素等理想条件下，三条谱线对应 三种同位素。速度选择器要求电场力和磁场力平衡，v=E/B。进入偏转区后 r=mv/(|q|B)，图示半圆轨迹的谱线距离 d=2r，故 m=|q|B²d/(2E)。若离子的电荷态不同，谱线对应的是荷质比，不能单凭条数直接断言同位素数量。

12-30 云室中的质子

先明确采用“速度垂直磁场、入口轨迹半径为0.20 m”的模型。由 p=|q|Br，非相对论动能 K=p²/(2mₚ)=e²B²r²/(2mₚ)。代入 B=1.0 T、r=0.20 m、e≈1.602×10⁻¹⁹ C、mₚ≈1.673×10⁻²⁷ kg，得 K≈3.07×10⁻¹³ J，除以1.602×10⁻¹³ J/MeV，得到 K≈1.92 MeV。

这是质子静能约938 MeV的0.2%，经典近似较好。若实际轨迹是螺旋线且有沿场速度，所见曲率只决定垂直动量，不能单凭该半径确定总动能；若沿途损耗改变半径，需使用入口处半径。

12-31 霍尔电压

单一电子载流子模型下，横向稳定时电场力与磁力抵消：|EH|=vdB。铜片电流 I=n|e|vdbd，两侧电压大小 |U|=|EH|b，消去漂移速度与宽度，得 |U|=IB/(n|e|d)。

题给 n=12.4×10²² cm⁻³。因为1 cm³=10⁻⁶ m³，所以 n=1.24×10²⁹ m⁻³；厚度 d=1.0 mm=10⁻³ m。代入 I=200 A、B=1.5 T、|e|=1.6×10⁻¹⁹ C，得到 |Uaa′|≈1.51×10⁻⁵ V=15.1 μV。

固定 I、n、d、B 时，宽度 b 增大使漂移速度和横向场减小，乘以 b 后抵消，所以不影响电压大小。电势高低应先按图示电子速度与 B 判断电子在哪侧积累；电子积累的一侧电势较低，大小公式本身不决定电压符号。
