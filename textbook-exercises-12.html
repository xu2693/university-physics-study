对应教材下册第 103—108 页。先画出电流、磁场和受力方向，再计算大小。μ₀ 取 4π×10⁻⁷ H/m 的常用近似。以下为独立学习解法；图中缺少的方向、材料或简化条件应与教材对照。

12-1 两电源电路

以 b 为零电势，a 的电势记为 V。先假设左、右支路的电流均流入 a，中央支路流出。两电源正极都在上，支路总电阻分别为 10+3=13 Ω 和 0.5+1.5=2 Ω，故节点方程

(12−V)/13+(8−V)/2=V/4，解得 V=256/43≈5.953 V。

代回得 I₁≈0.465 A（向右）；右支路实际流向 a 的电流约 1.023 A；中央支路 I₃≈1.488 A（向下）。按原图 I₂ 向右为正，I₂≈−1.023 A，负号表示实际方向相反。

检查：两侧流入之和等于中央流出，0.465+1.023≈1.488 A；电流与电阻的乘积具有电压单位。

12-2 两导线接到均匀圆环

圆环粗细均匀，两段圆弧电阻分别与弧长、圆心角成正比；两段电压相同，分流电流与电阻成反比，所以两段的“电流×圆心角”相等。圆弧在圆心的磁场大小正比于此乘积，而两段电流绕圆心方向相反，磁场相互抵消。径向引线的电流元与指向圆心的连线平行，也不贡献磁场，按细导线电流模型得到 B=0。

原题文字称“铁环”：若计入真实铁磁材料的磁化，题目未给磁化状态和材料性质，不能仅凭自由电流模型保证这一结论；上面的结果采用通常的细导线近似。

12-3 相互垂直的圆线圈

每个 N 匝圆线圈在圆心的磁场大小 B=μ₀NI/(2R)。半径先换为米：

B₁=(4π×10⁻⁷)×10×10/(2×0.20)=3.14×10⁻⁴ T；B₂=(4π×10⁻⁷)×20×5/(2×0.10)=6.28×10⁻⁴ T。

两线圈平面垂直，所以两场方向沿各自法线且互相垂直。矢量相加得 B=√(B₁²+B₂²)≈7.02×10⁻⁴ T，与 B₁ 的夹角 arctan(B₂/B₁)=arctan 2≈63.4°。具体空间指向还须由每个线圈的电流绕向和右手定则确定；仅给大小时不能凭空指定方向。

12-4 圆环与切线直导线

圆环电流顺时针，圆心磁场向纸内，大小 B环=μ₀I/(2R)；直导线电流向右，圆心在其上方，右手定则给 B直=μ₀I/(2πR)，方向向纸外。两场反向，且 B环/B直=π，因此相减得 B=μ₀I(π−1)/(2πR)，方向垂直纸面向里。相切处仅无限接近，并不接触短接。

12-5 三角形框与引线

均匀电阻使 a→b 直边分流 2I/3，经 a→c→b 的两边各为 I/3。正三角形中心到三边距离相同，三段在 O 的场按绕向相加后恰好抵消。引线 1 的延长线经过 O，对 O 无场；引线 2 从 b 水平向右，为半无限直线，O 到引线的垂距 l/√3，且垂足在 b。故 B=√3μ₀I/(4πl)，按图中方向垂直纸面向里。

12-6 无限长薄板旁的磁场

薄板沿宽度均匀分成电流元 dI=(I/l)dx，距 P 为 d+l−x。每条无限长电流元贡献 μ₀dI/(2π距离)，积分得 B=[μ₀I/(2πl)]ln[(d+l)/d]。图中电流沿 +y，P 在板的右侧，磁场沿 −z，即垂直纸面向里。

把宽度为 l 的薄板沿 x 方向切成许多平行的长直细条。均匀分布时一条宽 dx 的电流 dI＝(I/l)dx；P 到该条距离为 d＋l−x。它产生 dB＝μ₀dI/[2π(d＋l−x)]，各条磁场在 P 处方向相同，因此可直接积分：∫₀ˡdx/(d＋l−x)＝ln[(d＋l)/d]。对数内是两个长度之比，没有单位。

12-7 带电刚性回路转动

回路由两个不同半径的半圆弧和两段径向连接段组成，电荷随整个刚体转动。对线元 dq=λdl，速度 v=ωr，圆心处 dB=μ₀λω dl/(4πr)，方向沿转轴。两段半圆各贡献积分 π，两段径向连接各贡献 ln(b/a)。所以 B=μ₀|λω|[π+ln(b/a)]/(2π)。别漏掉径向连接段：它们随刚体转动，速度不是径向。

把电荷元当成运动电荷处理，不能把径向线段当作静止载流导线。距圆心 r 的电荷元速度大小为 ωr，且速度与半径垂直，所以它在圆心产生的磁场大小为 μ₀λω dl/(4πr)。对每个半圆弧，dl/r＝dθ，角度积分分别是 π；对两条径向连接段，dl＝dr，各贡献 ∫ₐᵇdr/r＝ln(b/a)。四部分方向相同，加总得到原式。

12-8 半圆柱面电流

柱面按角度分成平行无限长导线，dI=(I/π)dθ。各导线到轴线距离 R，横向对称分量抵消，另一分量的角积分为 2。故轴线上场强大小 B=μ₀I/(π²R)，方向在横截面内，按图中电流方向用右手定则确定。

12-9 密绕平面螺旋线圈

半径从 R₁ 到 R₂ 均匀分布 N 匝，单位径向宽度匝数为 N/(R₂−R₁)。把每匝近似为圆环，dB=μ₀I dN/(2r)，积分得 B=[μ₀NI/(2(R₂−R₁))]ln(R₂/R₁)。方向垂直线圈平面，以电流绕向确定；此为密绕近似。

分步积分：若 N 匝在 R₁ 到 R₂ 的径向宽度中均匀分布，则半径 r 附近宽 dr 内的匝数 dN＝N dr/(R₂−R₁)。这些匝近似为圆环，每匝在圆心产生 μ₀I/(2r)，故 dB＝μ₀I dN/(2r)。对半径从 R₁ 积分到 R₂，∫dr/r＝ln(R₂/R₁)，得到题解中的结果。这个模型把紧密螺旋近似为一系列同心圆。

12-10 两个反向转动的带电圆环面

半径 r、宽 dr 的圆环电量 dq=σ2πr dr，转速为 n 时产生电流 dI=n dq；圆心 dB=μ₀dI/(2r)=μ₀πσn dr。按图内环覆盖 R₁ 到 R₂、外环覆盖 R₂ 到 R₃，转向相反，令两磁场大小相等：n₁/n₂=(R₃−R₂)/(R₂−R₁)。

12-11 半球密绕线圈

沿半圆弧均匀分布意味着 dN=(2N/π)dθ。取 θ 为相对轴线的极角，一匝半径 R sinθ，距球心的轴向距离 R cosθ，圆环轴线上场 dB=[μ₀I/(2R)]sin²θ dN。积分 θ 从 0 到 π/2，得 B=μ₀NI/(4R)，方向沿公共轴线。这里的均匀是沿球面圆弧的匝数均匀，不是沿轴向均匀。

分步积分：把球面上一条绕轴的圆环单独取出。它的半径为 R sinθ，圆心到球心的轴向距离为 R cosθ；圆环轴线场公式给每匝 dB/每匝＝μ₀I sin²θ/(2R)。若匝数沿四分之一圆弧均匀，则 dN＝(2N/π)dθ，θ 从 0 到 π/2；利用 ∫₀^(π/2)sin²θ dθ＝π/4，得到 B＝μ₀NI/(4R)。

12-12 两根反向电流导线

中点距每线 0.20 m，两场方向相同，故 B=2μ₀I/(2π×0.20)=4.00×10⁻⁴ T，方向垂直纸面向里。设左线到面积元的距离为 x，矩形区域 x=0.10 到 0.30 m，第二线距该点 0.40−x。积分得通量大小 Φ=μ₀Il/π·ln3≈2.20×10⁻⁵ Wb；带符号结果取决于所选面法线。

磁通的积分步骤：图中两电流反向，在线间区域两者磁场都指向纸内，大小相加。以左导线为 x＝0、右导线为 x＝0.40 m，图中阴影区域横向范围 0.10≤x≤0.30 m，因此 Φ 的大小为对 x 从 0.10 到 0.30 m 积分：l∫[μ₀I/(2π)]·[1/x＋1/(0.40−x)]dx。两项积分各为 ln3，合起来为 μ₀Il ln3/π；代入 I＝200 A、l＝0.25 m，得约 2.20×10⁻⁵ Wb。通量正负还取决于所选面法线。

12-13 导体圆柱内部的磁通

r<R 时包围电流 Iᵣ=I r²/R²，安培环路定理给 B(r)=μ₀Ir/(2πR²)。穿过图中长 l、宽 R 的径向面，Φ=l∫₀ᴿB(r)dr=μ₀Il/(4π)。这是图示开曲面的通量；闭合面的总磁通恒为零。

先求半径 r 内包围的电流：电流在整个圆截面均匀分布，所以 I内/I＝πr²/(πR²)＝r²/R²。安培环路取半径 r 的同心圆，B·2πr＝μ₀I内，得 B(r)＝μ₀Ir/(2πR²)。图中所求是长 l、从轴线延伸到表面的径向开曲面；把面积分成 l dr，积分 l∫₀ᴿB(r)dr＝μ₀Il/(4π)。

12-14 同轴圆柱筒

两筒间 R₁<r<R₂，安培环路包围内筒电流 I，故 B=μ₀I/(2πr)，方向环绕轴线。通过图中长度 l 的径向截面通量大小 Φ=μ₀Il ln(R₂/R₁)/(2π)。

两个圆筒之间取半径 r、长度方向与筒轴平行的圆形安培环路。环路包围内筒电流 I，而外筒的回流在环路之外，所以 B·2πr＝μ₀I。再对径向截面的宽度积分：Φ＝从 R₁ 到 R₂ 的积分 ∫B(r)l dr＝μ₀Il ln(R₂/R₁)/(2π)。若环路取在外筒之外，去程与回程总包围电流抵消，在理想对称模型下外部磁场为零。

12-15 螺线环

理想密绕环内半径 r 处，安培环路定理 B·2πr=μ₀NI，故 B(r)=μ₀NI/(2πr)，D₁/2<r<D₂/2。截面高为 h，积分 Φ=∫B h dr=[μ₀NIh/(2π)]ln(D₂/D₁)。理想模型忽略漏磁和绕线离散性。

12-16 无限长圆柱面环向电流

面电流密度 jₘ 就是每单位轴长绕行的电流，等效无限长理想螺线管。轴线上 B=μ₀jₘ，方向由电流绕向按右手定则确定。该结果与半径无关，依赖无限长和均匀面电流条件。

12-17 无限大载流厚板

板平行 xz 平面，中心为 y=0，厚度 2d，均匀电流密度 j 沿 +z。对称性和安培定理给 B⃗=−μ₀jy î（|y|≤d）；y>d 时 B⃗=−μ₀jd î；y<−d 时 B⃗=+μ₀jd î。板内大小随离中心距离线性增加，板外大小恒定。

12-18 导线接到均匀环

图中短弧圆心角 120°，长弧 240°，电阻比 1:2，故电流分配为短弧 2I/3、长弧 I/3。图中的环路 L 只套住右侧短弧一次，因此对磁场强度 H 应用安培定理得 ∮L H·dl=±2I/3，正负由环路方向及右手法线决定。题目称环为铁环：B 的环流还受到铁磁材料磁化的影响，未给材料磁化状态时，不能直接把它确定为 μ₀ 乘以自由电流。若明确忽略磁化、按真空电流模型近似，才有 ∮L B·dl≈±2μ₀I/3。不要把总电流 I 当成 L 包围的短弧电流。

12-19 可转动 U 形导线

两侧边各长 a、底边长 a，单位长度质量 ρS。关于 OO′ 轴，重力矩大小为两侧边各 ρSag·(a/2)sinα，加上底边 ρSag·a sinα，总计 2ρSga²sinα。磁力矩大小 I a² B cosα。平衡得 B=2ρSg tanα/I。假设导线截面均匀、轴上的连接段不贡献力矩。

12-20 导轨电流与能量

按题目的理想半无限导轨模型，两条导轨在滑动物体上的磁场沿轨距积分，得到 F=[μ₀I²/(2π)]ln[(d+r)/r]。取题给 r=0.025 m、d=0.10 m，且理想情况下电流与推力恒定、忽略损耗，令 FL=33 MJ，得到 I≈2.26×10⁶ A。这是题设模型的数量级计算，实际装置的能量损耗、导轨与电源条件并不包含在内。

12-21 直导线旁的圆形电流回路

设 d>R。将圆环各电流元受到的 dF=I₂dl×B 积分，垂直导线方向的合力大小为 F=μ₀I₁I₂[d/√(d²−R²)−1]。按图示电流，圆环靠近直导线的一侧与导线同向，合力指向直导线。d≫R 时结果约为 μ₀I₁I₂R²/(2d²)。

12-22 磁场中的圆环张力

图示方向使每段导线受到径向向外的磁力。取小弧对应角 dθ，磁力大小 IB R dθ，两端张力指向圆心的合分量约 T dθ，故 T=IBR=0.010 N。假定磁场均匀、圆环细且处于静力平衡；若电流或磁场反向，径向力朝内，单凭电流不能推定同样的拉张力。

12-23 直导线下方矩形线框

上边必须与直导线电流同向才能被吸引向上：图中上边电流向右，因此线框电流顺时针。上边距导线 d、下边距 d+a，左右边的水平力抵消。向上净磁力 F=μ₀I₁I₂b[1/d−1/(d+a)]/(2π)，给定图示位置时，可平衡的重量上限等于此值。

12-24 薄金属板旁的矩形线圈

若板上电流在宽度 a 内均匀，板边外距离 x 处的场为 B(x)=μ₀I₁ ln[(x+a)/x]/(2πa)。设 MN、PQ 的长度为 L，分别距板边 b 与 b+c，则 F_MN=I₂L B(b)，朝向金属板；F_PQ=I₂L B(b+c)，背离金属板。若未知电流横向分布或边长 L，就不能仅凭总电流写出唯一数值；两边合力方向指向板。

12-25 旋转带电圆盘的磁力矩

半径 r、宽 dr 的环带 dq=σ2πr dr，旋转周期 2π/ω，等效电流 dI=σωr dr。环的磁矩 dμ=dI·πr²，积分 0 到 R：μ=πσωR⁴/4。磁矩与外场垂直，故力矩大小 τ=π|σω|R⁴B/4。方向由 μ⃗×B⃗ 判断。

12-26 方形线圈磁矩

每匝面积 (0.150 m)²=0.0225 m²。磁矩 μ=NIS=200×0.8×0.0225=3.60 A·m²；最大力矩 τ最大=μB=14.4 N·m，发生在线圈磁矩垂直磁场时。

12-27 电子的经典旋转模型

均匀带电球壳绕直径旋转，积分各纬圈磁矩得 |μ|=|e|ωR²/3。取 R=10⁻¹⁸ m、|μ|=0.928×10⁻²³ J/T，则赤道速率 v=ωR=3|μ|/(|e|R)≈1.74×10¹⁴ m/s，远大于光速。更小的假设半径只会使所需速率更大，因此这个刚性带电球壳的经典模型不合理；电子自旋不能直接解释为小球表面真的这样旋转。

12-28 地磁场中的电子

速度向北、磁场向下。对正电荷 v×B 指向西，电子带负电，故初始受力向东。非相对论近似 v=√(2K/m)≈6.50×10⁷ m/s，a=evB/m≈6.28×10¹⁴ m/s²，轨道半径约 6.72 m。南北方向前进 0.20 m 时，圆弧几何给横向偏移 R−√(R²−0.20²)≈2.98 mm，向东。12 keV 相对静能约 2.3%，更精确计算应使用相对论动量；上述是教材常用近似。

12-29 质谱仪

在同一电荷量、每条谱线对应一种同位素等理想条件下，三条谱线对应 三种同位素。速度选择器要求电场力和磁场力平衡，v=E/B。进入偏转区后 r=mv/(|q|B)，图示半圆轨迹的谱线距离 d=2r，故 m=|q|B²d/(2E)。若离子的电荷态不同，谱线对应的是荷质比，不能单凭条数直接断言同位素数量。

12-30 云室中的质子

若速度垂直磁场且按经典近似，r=mv/(eB)，故 K=e²B²r²/(2mₚ)≈1.92 MeV。此处动能约为质子静能的 0.2%，经典近似较好；如果轨迹半径在进入后因介质损耗改变，应使用对应入口处的曲率。

12-31 霍尔电压
