量子信息入门：量子比特、测量与纠缠

本篇配合第 18 章，建立量子信息的基本概念；例题为新编。扫描教材正文和进阶细节仍待逐页核对。

一、经典比特与量子比特

经典比特在读取时表示 0 或 1。一个理想量子比特的纯态可以写作 |ψ⟩=α|0⟩+β|1⟩，其中 α、β 一般为复数，且 |α|²+|β|²=1。|0⟩ 和 |1⟩ 是选定测量基下的两个基态；α、β 称为概率幅，不是概率本身。

如果沿这个计算基测量，得到 0 的概率是 |α|²，得到 1 的概率是 |β|²。理想的投影测量后，态相应变为与结果对应的基态；其他测量模型及噪声情形需要另行描述。

例 1：|ψ⟩=(√3/2)|0⟩+(1/2)|1⟩。测得 0 的概率为 3/4，测得 1 的概率为 1/4，两者相加为 1。不能把幅度 1/2 当成结果 1 的概率。

二、叠加与经典随机混合不同

叠加态的幅度有相位，后续操作中不同路径的概率幅可以干涉；经典随机混合则以经典概率随机选择状态，不能无条件表现出相同干涉。要区分两者，需要指定制备方式和测量方式；仅看某一个测量基下的 0、1 统计结果，有时无法区分。

整体乘以同一个不可观测的全局相位不会改变单个纯态的测量概率；分量之间的相对相位可以影响在其他基下的测量。讨论“相位”时要区分这两种情况。

三、两个量子比特

两个比特的联合空间由 |00⟩、|01⟩、|10⟩、|11⟩ 四个计算基态张成。一个联合纯态如果能够写成第一个量子比特的态与第二个量子比特的态的直积，就是可分态；若不能写成这样的直积，则是纠缠态。

例 2：贝尔态 |Φ⁺⟩=(|00⟩+|11⟩)/√2。两方都在计算基测量时，00 和 11 各以 1/2 概率出现，01、10 不出现。每个人单独看到 0、1 的概率都是 1/2；把双方记录对照，才能看到这里描述的完全相关。

不能把纠缠简单等同于“测到相同结果”：某些经典相关系统也可以在一个基下表现相同结果。贝尔不等式及合适的多种测量设置用于检验局域隐变量模型可达到的关联范围，具体结论依赖实验假设和设置。

四、纠缠能传递超光速消息吗？

不能仅靠一方选择测量操作或期望得到的结果，向远方单方面发送可读取的信息。单次测量结果不能任意指定；另一方的本地统计不会因对方选择局部测量而变成可用来无条件通信的消息。要利用双方关联完成协议，通常还需要经典通信。

这不否认纠缠带来的非经典关联；它说明关联和可控传信是不同概念。

五、量子门与测量

理想量子门对应保持态归一化的幺正变换。常见例子：X 门交换 |0⟩ 与 |1⟩；H 门把 |0⟩ 变成 (|0⟩+|1⟩)/√2。先后顺序重要：门操作后还需根据最终态和测量基计算概率。

例 3：从 |0⟩ 出发，先施加 H 门，再按计算基测量，得到 0 或 1 的概率各为 1/2。若再施加一次理想 H 门，由 H²=I，最终回到 |0⟩，测得 0 的概率为 1。这个结果依赖相干演化；如果两次门之间先进行了测量，就不能忽略测量对态的影响。

六、量子通信和量子计算的边界

量子密钥分发利用量子态及测量性质帮助通信双方检测窃听，安全性取决于具体协议、器件与假设；它不意味着所有通信自动安全。量子计算利用量子态演化和干涉实现算法，但量子计算机并不保证对每个问题都比经典计算机快，实际性能也受噪声和纠错条件限制。

六点一、为什么不能复制任意未知量子态？

不可克隆定理说，不存在一种固定的理想量子操作，能把任意未知量子态和同一个空白态输入，并总是输出两份完全相同的该态。这不妨碍复制已知且互相正交的基态，也不排除针对特定有限集合的其他策略。

直观推理：假设一种操作能把 |0⟩ 和 |1⟩ 都分别复制，且对输入保持量子演化的线性。那么输入 (|0⟩+|1⟩)/√2 时，输出是 (|00⟩+|11⟩)/√2；但两份原叠加态的直积还包含 |01⟩ 和 |10⟩ 项。两者不同，因此这台设备不能同时复制所有叠加态。

六点二、量子隐形传态传送什么？

标准量子隐形传态协议可以将一个未知量子比特的状态转移给远方接收者：双方事先共享一对纠缠比特，发送者对待传态与自己手中比特进行联合测量，再把两个经典比特的测量结果发给接收者；接收者依据结果作相应操作。

协议传递的是量子态，并不是物体或粒子本身被瞬间搬运；原始待传态在测量过程中不再保留为原样，因此不违反不可克隆定理。经典信息仍需传递，不能据此超光速发送可控消息。上面是理想协议；噪声会影响实际保真度。

六点三、量子密集编码

若双方事先共享一个理想贝尔对，发送者可对自己持有的量子比特选择四种约定操作之一，再发送这个量子比特；接收者通过对两个比特的联合测量，理想情况下可区分四种情况，即获得两位经典信息。

这并不意味着一个从未共享资源的普通量子比特单独承载了可无条件读取的两位信息：协议预先消耗了共享纠缠，而且发送的量子比特本身仍要经过物理信道。不要把密集编码和隐形传态需要的资源方向混淆。

七、自测与解答

1. |ψ⟩=(1/√2)|0⟩+(1/√2)|1⟩，计算基测量 1 的概率是多少？

解：幅度的模平方为 |1/√2|²=1/2。

2. 对贝尔态 |Φ⁺⟩，双方都测量计算基，一方只看自己的结果能否知道对方想发送的任意消息？

解：不能。单方结果为随机的 0 或 1，关联需双方比较，不能靠任意指定测量结果来发送消息。

3. |0⟩ 经 H 门两次后，理想情况下测得 0 的概率是多少？

解：若中间没有测量且操作理想，由 H²=I，最终为 |0⟩，概率为 1。

学完自检

能区分概率幅与概率；知道测量依赖所选基；能描述贝尔态在计算基的关联；知道纠缠不等于可控超光速通信；知道量子算法优势取决于具体问题。
